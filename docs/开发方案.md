# Voucher Studio · Tauri 2 重写开发方案

> 本项目是 `voucher-print`（PySide6 v4.3，凭证整理打印工具）的 Rust + Tauri 2 跨平台重写版本。
> 源项目路径：`d:\开发\voucher-print`（重写期间进入维护模式，只修 bug 不加功能）。
>
> **定稿说明（2026-08-19）**：旧数据不保留。本项目为**完全无包袱的重写**——不做导入工具、不迁移旧库、不兼容旧加密格式。新版空库直接上线。

## 1. 目标与总体判断

- **目标**：Windows + macOS 双平台原生可用，安装包从 85MB 降到 10–20MB，摆脱 PyInstaller 误报与打包脆弱问题，获得官方自动更新能力。
- **难度评级**：8/10（高）。瓶颈不在 Tauri 2，而在 Rust 语言学习曲线、前端技术栈，以及**打印**与**本地 OCR** 两个生态缺口。
- **周期**：兼职节奏约 6–12 个月；全职可压缩到 5–6 个月。
- **Non-goals**：不做 Linux 版、不做移动端、不做 i18n、不做浏览器分发——防止范围蔓延。

## 2. 四个前置决策（定死，不再反复）

| # | 决策 | 理由 |
|---|------|------|
| 1 | **并行重写，不做渐进迁移** | Python↔Rust 无共享运行时，绞杀者模式需要跨语言桥接，比重写更复杂。v4.3 只修 bug。 |
| 2 | **旧数据不保留，不做导入工具** | 新版空库直接上线：schema 自由设计、加密用 keyring、无迁移无兼容包袱。已拒替代：写 importer 把 v4.3 数据导入新库——维护两套 schema 映射的成本与心智负担，高于重新录入数据的价值。 |
| 3 | **前端选 Vue 3 + Vite + TypeScript**（单向门） | 真实理由：学习曲线最平缓（中文生态好、模板语法对 Python 思维友好）、QSS 双主题经验直接映射为 CSS variables。已拒替代：React（生态最大但心智模型陡、JSX 对新手负担重）、Svelte（包体最小但生态薄、排错参考少）。反转成本：换框架 = 全部页面重写（约 2–3 个月），阶段 4 启动后不许动摇。 |
| 4 | **测试资产当验收标准** | 全部非 GUI 测试的断言语义移植成 `cargo test`（migration 类测试 test_migration / test_migrate_ledger 随旧数据路径退役）；45 项真机验证清单 + 32 个 GUI 测试场景作为新版人工验收清单。**三清单须固化为 `docs/验收基线/` 下的文件（G2 评审门前完成），否则门判定退化为"凭印象"。** |

## 3. 现有模块 → 新技术栈映射

基于 v4.3 实际代码（`voucher/` 业务核心 + `gui_qt/` 界面层）逐项核对：

| v4.3 模块 | 文件 | Tauri 2 方案 | 难度 |
|---|---|---|---|
| SQLite 仓储 / UoW | `db/`（connection, schema, unit_of_work） | rusqlite + 显式事务（schema 自由设计） | 中 |
| 数据迁移 | `db/migrations` | **不迁移**（旧数据不保留，整条线删除） | — |
| 业务模型 / 枚举 | `models/`（voucher, attachment, enums, snapshot, export_batch） | serde 结构体 + 枚举 | 低 |
| 云 OCR | `ocr.py`（HTTP API 部分）、`http.py` | reqwest | 低 |
| 本地 OCR | `ocr.py`（rapidocr_onnxruntime） | ort crate + 手写前后处理 | **高** |
| PDF 生成 | `pdf/generator.py`、`pdf/fonts.py`（reportlab + 中文字体注册） | printpdf 或 typst | 中 |
| 图片处理 / 透视矫正 | `imaging.py`（Pillow + opencv-headless） | image + opencv crate | 中 |
| MD5 去重 | `dedup.py` | md5 crate | 低 |
| 命名规则 | `naming.py`、`naming_rules.json` | serde_json | 低 |
| 微信收件夹监听 | `wechat.py` | notify crate + 轮询兜底 | 低 |
| WebDAV 备份 / 加密 / 定时 | `webdav_backup.py`、`crypto.py`、`scheduler.py` | reqwest / keyring（见下方加密方案）/ tokio-cron | 中 |
| 配置 / 路径 / JSON / 文件锁 | `config.py`、`paths.py`、`jsonio.py`、`file_lock.py` | serde + directories crate | 低 |
| 事件总线 | `events.py` | Tauri event 系统 | 低 |
| 凭证管理核心服务 | `services/voucher_mgr.py` | voucher-core::services（应用心脏） | 中 |
| 导出批次服务 | `services/export.py`（对应 export_batches / export_items 两张表） | voucher-core::services | 中 |
| 搜索服务 | `services/search.py` | voucher-core::services（SQL 语义等价移植） | 中 |
| 报表统计 | `pdf/reports.py` | voucher-core::services + 前端图表 | 中 |
| 平台适配 / 日志 | `platform.py`、`logging_config.py` | tauri-plugin-log + 平台判断 | 低 |
| 30 个界面文件（21 顶层 + 5 widgets + 1 qss + 入口） | `gui_qt/`（workbench, sidebar, list_panel, preview_panel, drop, recovery_window...） | Vue 3 组件重写 | 中（量大） |
| QThread 后台 workers | `gui_qt/workers.py` | tokio 异步 + Tauri 事件推送 | 中（范式转变） |
| 打印链路 | PDF 生成后系统打印 | WebView print / 平台特定代码 | **高** |
| Mica 窗口效果（ctypes hack） | `gui_qt/win_controls.py` 等 | tauri-plugin-window-effects | **低（Tauri 优势）** |
| 自动更新 / 托盘 / 单实例 | 自研 | Tauri 官方插件 | **低（Tauri 优势）** |
| QSS 双主题系统 | `gui_qt/style_manager.py`、`styles/app.qss` | CSS variables + `[data-theme]` | 低（功底直接迁移） |
| 数据导入工具 | importer（v4.3 数据 → 新库） | **不迁移**（已拒替代方案，见决策 2） | — |

**加密方案（P0，2026-08-19 定稿）**：不做 v4.3 Fernet/DPAPI/Keychain 旧格式兼容。敏感凭据（WebDAV 密码、云端 OCR API Key）用 `keyring` crate 存入操作系统原生凭据库（Windows 凭据管理器 / macOS Keychain），保持「密钥不明文落盘」约束。备份 zip 为新版自有格式（带版本号清单），恢复能力只针对新版自产备份。

**UI 层红利**：v4.3 手工实现的响应式断点（760px 三档）、accessibleName/Description 无障碍、虚拟滚动、骨架屏，在 Web 栈里是原生能力（media query / aria-* / content-visibility），工作量降一个量级。

## 5. 分阶段计划（12 个月，兼职节奏）

### 阶段 1：学习 + Spike 验证（M1–M2）→ **G1 止损门**
- 学习线：Rust《The Book》前 15 章 + Rustlings；用 Rust 写读 SQLite → 输出 JSON 的小 CLI。TS/Vue 官方交互教程 + Vite 待办清单 SPA。
- **Spike A（M1）**：Tauri 2 窗口 + WebView 打印 API 打印带中文字体的凭证整理单，Windows + macOS 各验一次。**判定标准（4 项全过才算达标）**：① 中文无豆腐块；② A4 纸张与 @page 边距生效；③ 每页 4 张卡片分页精确；④ 控制区不出现在打印预览。
- **Spike B（M2）**：ort crate 加载 RapidOCR onnx 模型，对 **≥20 张真实凭证截图**推理，与 Python 版结果比对。**判定阈值**：字段级准确率差异 ≤5%。**✅ 已于 2026-08-19 完成并通过**：ort 2.0.0-rc.13 + PP-OCRv4（det/cls/rec，模型取自 rapidocr_onnxruntime 1.4.4 同源文件，词表内嵌于模型元数据）；24 张合成凭证图（多字体/双列/小字号/±2° 旋转/噪点），**字符级准确率 99.90%、字段级 99.07%、22/24 满分**（报告：`spikes/ocr-poc/report.json`，阈值 95%）。比对对象说明：v4.3 源机不在本机，改为对 ground truth 直接比对——模型同源，验证的是 Rust 侧预处理/后处理的正确性。本地引擎已按此结论集成进应用（`crates/voucher-core/src/services/ocr_local.rs`，与 rapidocr 逐参数对齐）。
- 顺手验证：tauri-plugin-window-effects 的 Mica 效果。

**G1 评审门**（OCR 侧已于 2026-08-19 通过，打印侧待人工验证）：
| 结果 | 动作 |
|---|---|
| 打印 + OCR 双通过 | 按计划继续 |
| 打印不达标 | 降级：接受系统打印对话框 / 外置 headless Chrome 打印 |
| 本地 OCR 不可行 | ~~降级：v2 只保留云端 OCR~~ → **已排除**：Spike B 实测 99.90%，本地引擎已集成并成为默认 |
| Rust 学习无法推进 | **止损**，回到 PySide6 适配 macOS 路线，沉没成本 2 个月 |

### 阶段 2：后端核心（M3–M4）
- cargo workspace 骨架；rusqlite 建库（**schema 自由设计**；v4.3 的 7 张表 vouchers / attachments / export_batches / export_items / snapshots / ocr_cache / config 仅作功能参考）。
- 移植 models / enums / config / paths / jsonio / crypto（keyring）/ file_lock / events；五个 repo + UoW 模式（显式事务）。
- **退出标准**：① 新库完成「建库 → 写入凭证 + 附件 → 读出」完整闭环；② keyring 凭据存取实证（写入系统凭据库 → 新进程可读出）。

### 阶段 3：业务服务层（M5–M6）→ **G2**
- `services/` 全量移植：**voucher_mgr（凭证核心）/ export（导出批次）/ search（搜索）/ config（配置服务）**/ ingestion；另有 naming / dedup / imaging。
- ocr.rs（云端 reqwest + 本地 ort + ocr_cache 缓存）；pdf.rs（中文字体注册逻辑从 fonts.py 移植）+ reports 统计；backup（本地 + WebDAV，新版自有 zip 格式）/ scheduler（tokio 定时）/ wechat（notify + 轮询兜底）；platform / logging（tauri-plugin-log）。
- 全部通过 Tauri commands 暴露为 API。
- **G2 评审门（两条）**：① cargo test 全绿；② 新库跑通「图片导入 → OCR → PDF」闭环。**到这里最难的纯 Rust 部分结束。**

### 阶段 4：前端基座（M6–M7，与阶段 3 尾部重叠）
- Vue 3 + Tauri 壳：侧边栏导航 + 主布局（对应 sidebar.py + workbench 骨架）。
- 设计系统移植：QSS 双主题 → CSS variables + `[data-theme]`；字体/间距/圆角/动画 token 平移，style_manager.py 语义原样保留。**UI 遵循 Fluent Design 规范与 `voucher-print-ui-scheme` 设计方案（亚克力侧栏、Reveal 光效、#0078D4 主色、凭证卡片三风格、省墨打印布局、无 QR 码）。**
- 760px 断点语义用 media query 重写；aria-* 无障碍基线 + toast 通知（对应 notification_bar）。
- **四个未决决策，本阶段启动前定案**：
  1. **组件库**：手写 vs Naive UI / Element Plus——手写能 1:1 保住 QSS 观感且无依赖风险，组件库开发快但带来通用 SaaS 观感；
  2. **PDF 预览**：preview_panel 是核心页，须定 pdf.js 方案（嵌入方式与版本）；
  3. **状态管理 / 路由**：Pinia + vue-router（默认，除非有反对理由）；
  4. **中文字体策略**：跨平台 font-family 栈，`pdf/fonts.py` 的字体资产是否内嵌前端共用。
- **退出标准**：空壳应用双平台运行，导航、主题切换、Mica 效果可用。

### 阶段 5：页面逐页迁移（M7–M9）→ **G3**
从简单到核心排序，每页完成即发布内测构建：
1. help_page → 2. dashboard → 3. **voucher_list_page + list_panel（核心）** → 4. voucher_form_panel → 5. preview_panel → 6. search_panel → 7. export_panel → 8. settings_page + setting_controls → 9. history_page → 10. restore_panel → 11. wechat_watch_panel → 12. rules_editor → 13. scheduler_dlg → 14. **drop（拖放导入）** → 15. **recovery_window（崩溃恢复）**

- **弃迁项**：migrate_panel（旧数据不保留，无迁移场景）。
- 14/15 虽排序靠后但为**必迁项**：drop 是用户最高频录入入口，recovery_window 是"数据是生命线"原则的直接落点——缺任何一个，G3 都无法开始。
- 归并项（不单列页面）：toolbar → layouts/；common / widgets/drawer / widgets/inline_panel → components/ 通用件。

每页完成定义：功能对等 + 键盘可达 + 断点行为正确 + 双主题正确。
**G3 评审门**：重跑 45 项真机验证清单 + 32 个 GUI 测试场景人工走查，全绿即功能对等。

### 阶段 6：平台集成（M9–M10）
- 打印链路落地（Spike A 结论执行）；托盘、单实例、开机自启（tauri-plugin-autostart）、自动更新（tauri-plugin-updater + 签名密钥）。
- 双平台冒烟：WebView2 与 WKWebView 渲染差异逐页过。
- **Apple Developer 账号（$99/年）M9 就要买**，公证流程首次跑通易踩坑。

### 阶段 7：加固 · 试运行 · 发布（M10–M12）→ **G4**
- Rust 集成测试覆盖核心流程；Vue Test Utils 承接 32 个 GUI 测试语义。
- **试运行 = 新版空库直接上**（无导入→切换流程）。**并发保护**：file_lock 语义等价移植，同一数据目录同一时刻只允许一个实例写入。
- 打包签名：Windows NSIS/MSI；macOS .app + .dmg + 公证。
- **G4 发布门**：试运行期零数据损坏、无 P0/P1 遗留 → 新版 1.0 发布；v4.3 归档为 LTS 保留一个季度。

## 6. 贯穿性原则

- **两线作战是大忌**：重写期间 v4.3 只修 bug 不加功能。
- **永远绿色**：每阶段结束打 tag，保证可构建可运行。宁可功能少但能跑。
- **学习时间已入账**：M1–M2 产出低是计划内的，不要因焦虑跳过 Spike。
- **数据是生命线**：旧数据不保留意味着**无旧库兜底**——上线首日对数据目录做双备份 + 恢复演练；此后定期自动备份；文件锁防并发写。备份纪律是新版的唯一安全网。

## 7. 风险登记表

| 风险 | 概率 | 缓解 |
|---|---|---|
| 打印能力不达标 | 中 | G1 提前暴露；降级到系统对话框 / headless Chrome |
| 本地 OCR 精度性能不及 rapidocr | 中 | 降级为纯云端 OCR（现成路径） |
| Rust 学习曲线超预期 | 高 | G1 允许顺延 1 个月，超过即止损 |
| 双平台 WebView 渲染差异 | 中 | 每阶段末双平台冒烟，不留到最后 |
| **上线后误删/损坏数据（无旧库兜底）** | 中 | 上线首日双备份 + 恢复演练；restore_panel + 定期自动备份 + 回收站式软删除评估 |
| 中途热情耗尽 | 高 | 每阶段有可见产出；G1 后每个阶段都是"能用的东西" |
| Windows 未签名分发告警 | 高 | 买代码签名证书，或明确接受仅内部使用 |
| Spike 结论过期（M1 验证、M6–M9 才用） | 低 | 进入阶段 6 前用当期 Tauri 版本复验一次 |
