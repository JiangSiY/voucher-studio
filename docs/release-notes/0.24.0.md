# Voucher Studio 0.24.0

这一版把整个界面重做成 **Loon for Mac 的玻璃卡片风**：鼠尾草渐变画布、20px 大圆角半透明卡片、
原生 Liquid Glass 材质与统一的大标题工具栏。所有页面——待处理、全部凭证、洞察、设置、
打印与导出、帮助、备份与恢复、搜索、新建凭证——现在是同一套视觉语言。

同时修掉了一个存在已久的深色模式缺陷：**打印预览在深色主题下白底白字、几乎不可读**。
现在纸面永远是白纸黑字，和最终 PDF 一致。

## 本版做了什么

### 视觉

- **渐变画布**：窗口底层改为鼠尾草绿灰渐变，左上与右下各一处柔光；内容区不再是一整块白色，
  而是让画布透出来。
- **玻璃内容卡**：卡片统一 20px 圆角、半透明白底、1px 发丝边、一层软托起，并叠加
  `backdrop-filter` 模糊；卡内嵌板降为更暗的一层，不再层层发亮。
- **原生材质**：继续使用 macOS 26+ 的 `NSGlassEffectView`；侧栏与窗口材质叠加后仍能看到
  桌面透出的层次。不支持模糊、开启「减少透明度」时自动回退到实色卡。
- **侧栏**：选中项从 macOS 27 的左侧 3px 竖条改为淡色胶囊；行高、圆角与整体节奏统一。
- **工具栏**：56px 高、透明、无下边线；页面大标题（22px）+ 同行小灰字副标题，标题落在
  工具栏垂直中线上。副标题由路由声明，页面内不再重复大标题。
- **控件**：输入框、按钮、搜索框、分段控件统一为半透明 field 材质；圆角、控件高度仍跟随
  「界面字号」三档缩放。

### 页面

- **待处理**：待办区改为一张玻璃卡，一行一件、行高 52；计数用 24px 指标数字。
- **全部凭证**：筛选条改为吸顶玻璃浮条；列表与右侧检视器各一张玻璃卡；没有选中凭证时
  列表卡独占整行，不再留半边空白。
- **洞察**：三张台账卡在 1280 宽下同排，月度透视独立玻璃卡；时间窗切换改为胶囊轨道。
- **设置**：六个分区的切换条浮在画布上，正文收进一张大玻璃卡。
- **打印与导出**：选图列表、打印选项保持玻璃层次；右侧纸张预览始终白底墨字。
- **其余页面**：帮助、备份与恢复、搜索、新建凭证、重复核查、导出历史均继承同一套玻璃卡与排版。

### 修复

- **深色下打印预览白底白字**：`.print-area` 过去写死白底，文字却继承深色主题的白色；
  现在纸面局部覆盖为 `--paper-*` 墨色，深色主题下也能正常阅读。
- **资料库空态只占左栏**：未选中凭证时列表卡现在独占整行。
- **洞察卡片标题折行**：「存储占用」在三卡同排时被挤成两行，现在标题保持一行、口径说明允许折行。
- **工具栏标题贴顶**：副标题原竖排在标题下方，把标题顶到工具栏上沿；改为同行基线排列后，
  标题下移约 12px（1.15 倍字号实测 top 12 / 中心 28）。

### 可读性与无障碍

- 保留「界面字号」三档（标准 / 大 / 更大），标题、正文、辅助文字、控件高度全部按比例缩放。
- `prefers-reduced-transparency`：去掉卡片模糊并换成实色，画布改纯色。
- `prefers-reduced-motion`：动效令牌归零；`prefers-contrast: more`：发丝边与次要文字加深。
- 侧栏浅色保持低 alpha 的玻璃观感、深色保持深色高 alpha，避免随桌面壁纸忽明忽暗。

### 维护

- 新增 `loonVisualContract` 8 例，锁住画布渐变、玻璃卡四件套、工具栏副标题、纸面墨色、
  减少透明度回退与页面标题去重；同步改写筛选条与吸顶两处旧契约。
- 前端 vitest 实测 **57 文件 / 360 用例**；typecheck / lint / format / build 全绿。
- Rust 侧本版无逻辑改动。

> 更新功能从 0.22.4 起生效。装 0.22.4 或更新的版本，可以在
> `设置 → 通用 → 检查更新` 里直接升到本版。

## 安装与校验

本版**未做 Apple 公证**（没有开发者账号签名），首次打开需要：

1. 把 `Voucher Studio.app` 拖进「应用程序」；
2. 右键 → **打开**（或系统设置 → 隐私与安全性 → 仍要打开）；
3. 如果仍提示已损坏或无法验证，执行：
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Voucher Studio.app"
   ```

**自检依赖是否齐全**（本版应当只打印 `@rpath` 与系统框架，没有任何 `/Users/…` 输出）：

```bash
otool -L "/Applications/Voucher Studio.app/Contents/MacOS/voucher-studio" | grep -v @rpath
```

如果这条命令打印出 `/Users/...` 开头的路径，说明装的是旧版（0.22.2 及更早），请下载新版。
