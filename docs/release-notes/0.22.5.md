# Voucher Studio 0.22.5

这一版把**凭证关联**的收尾工作补齐：列表里能直接看到每张凭证有多少条关联并就地展开，
日报附页与「关联清单.csv」不再把同一对凭证重复列两遍。

## 本版做了什么

### 新增

- **列表行「关联 N」徽标**：凭证只要与别的凭证有关联（附件说明 / 明细）或进了事项组，
  列表行上就会出现徽标；点一下就地展开对方编号、日期、金额与说明，点条目可直接跳到那张凭证。
  一页只查一次，不会因为列表变长而变慢。

### 修复

- **日报附页不再重复列同一对**：以前同一天的两张凭证只要互相有关联，附页会把「A→B」和「B→A」
  各列一行，按类型的小计金额也跟着重复计一遍；现在同一对只出现一次，小计只算一次。
  「关联清单.csv」走同一份数据，一并修正。
- **事项组操作补上留痕**：建组、加成员、移出成员、删组现在都会写进审计表
  （`voucher_group_events`），与凭证关联的「关联 / 解除」留痕并列；老库升级时自动补表，不动已有数据。

### 维护

- 备份恢复补了关联相关的回归断言：备份后恢复，关联、事项组、两张审计表都必须完整回来
  （以前只断言凭证张数）。
- 发版脚本与清理脚本三处收口：预检加锁文件一致性、清理时保留本版的 `latest.json` / `sha256sums.txt`、
  CI 的打包冒烟只出 `.app`（dmg 始终由 `package-macos.sh` 产出），避免再出现包引用本机 OpenCV 路径的问题。

> 更新功能从 0.22.4 起生效。如果你装的是 0.22.4，可以在
> `设置 → 通用 → 检查更新` 里直接升到本版。

## 安装与校验

本版**未做 Apple 公证**（没有开发者账号签名），首次打开需要：

1. 把 `Voucher Studio.app` 拖进「应用程序」；
2. 右键 → **打开**（或系统设置 → 隐私与安全性 → 仍要打开）；
3. 如果仍提示已损坏或无法验证，执行：
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Voucher Studio.app"
   ```

**自检依赖是否齐全**（本版应当没有任何 `/Users/…` 输出）：

```bash
otool -L "/Applications/Voucher Studio.app/Contents/MacOS/voucher-studio" | grep -v @rpath
```

如果这条命令打印出 `/Users/...` 开头的路径，说明装的是旧版（0.22.2 及更早），请下载新版。
