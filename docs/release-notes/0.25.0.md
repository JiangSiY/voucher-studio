# Voucher Studio 0.25.0

这一版把**台账**接进了 App：以前月度清单要在命令行里跑，现在侧栏多了一个「台账」页，
从一个 CSV 开始，**导入 → 补附件 → 等入账** 一路走完，每次导入记成一批，可回看、可整批撤销。

顺带把 PDF 收进附件体系（多页 PDF 归成一条附件，不拆页、不做 OCR），
并修掉了一个会让整批导入中断的崩溃。

## 本版做了什么

### 新增：台账页

- **侧栏「台账」**：夹在「全部凭证」和「重复核查」之间，行尾徽标就是**待补附件张数**，
  和页面里的数字同源，补一张图徽标就减一。
- **三段流水线**：
  - **待补附件** —— 有台账号、还没有图的凭证，行内「挂附件」直接选图/PDF 挂上去；
  - **待入账** —— 有图、还没进金蝶的凭证，勾一下「已入账」就移出队列（只是人工标记，
    不涉及金蝶凭证号）；
  - **批次** —— 每次导入一批，显示导入时间、类型、文件名、新建/命中/坏行数。
- **导入向导四步**：选类型（收款 / 付款 / 计提）→ 选 CSV → **自动预演** → 写入。
  预演会先说清「这次会新建几张、已有几张、哪几行有问题」，坏行可以展开逐行看原因
  （日期空/不合法、金额不是数字、台账号空…）；如果全部命中、一张都新建不出来，
  写入按钮直接置灰并说明原因，避免「以为导了其实没导」。
- **批次可撤销**：撤销一次导入，只删「这批新建的 + 还没补附件 + 没导出过」的凭证，
  其余逐条列出保留原因（有附件 / 已导出 / 已归档）；批次记录本身不物理删除，标成「已撤销」。
- **幂等**：台账号（流水号 / 单据号）是唯一键，同一个月同一张清单重复导，
  第二次全是「已存在」，不会造重复凭证。
- **待处理页**新增一张只读待办卡「台账凭证待补附件 N 张」，清零即消失。

### 新增：PDF 附件

- 导入时可以选 PDF，多页 PDF 归成一条附件并记页数；不做 OCR 增强，
  识别流程仍只针对图片。
- 既有图片凭证不受影响（旧附件一律按图片处理，升级后显示照旧）。

### 修复

- **清单里空日期会让整批导入中断**：计提清单里某行日期为空时，取年月会直接越界崩溃
  （整批随之中断，已写进去的也停在半路）。现在日期校验是**行级**的：坏行进错误明细、
  其余行照常写入，错误明细同时落盘成 `exports/import-errors-<时间戳>.csv`。
  顺带容忍 `2026/10/1`、`2026-10-01 12:00:00` 这类写法，统一规范化成 `YYYY-MM-DD`。
- **中文 CSV 编码**：导出的清单带 BOM 或 GB18030 时也能正确读入（先按 UTF-8 试，
  不合法再回退 GB18030）。

### 命令行（给自动化用的）

- 新增 `crates/voucher-cli`：`import-ledger --csv <文件> --kind <shoukuan|fukuan|jiti> [--dry-run]`、
  `list-pending [--json]`，退出码 0/1/2，供 `财务工作流/tools/ledger_to_voucher.py` 调用。

### 维护

- 资料库结构**只增不改**：新增 `import_batches` 表，凭证表补 `import_batch_id`、`ledger_booked_at`
  两列，附件表补 `is_pdf`、`page_count` 两列；升级自动补，不清库、不动数据。
- Rust 330 例（172 单元 + 158 集成，加壳 3 共 333）、前端 59 文件 376 例；
  typecheck / lint / format / build / clippy / fmt 与两道 grep 守卫全绿。

## 升级须知

本版**第一次打开**会升级资料库结构（加两列一张表，只增不删）。**升级前请先备份**
（`备份与恢复 → 立即备份`，或直接复制 `~/Library/Application Support/VoucherStudio/voucher.db`）。

第一次在台账页点「导入清单」时，建议先只做预演、核对新建/命中数与清单行数是否吻合，
再点写入。

> 更新功能从 0.22.4 起生效。装 0.22.4 或更新的版本，可以在
> `设置 → 通用 → 检查更新` 里直接升到本版。

## 安装与校验

本版**未做 Apple 公证**（没有开发者账号签名），首次打开需要：

1. 把 `Voucher Studio.app` 拖进「应用程序」；
2. 右键 → **打开**（或系统设置 → 隐私与安全性 → 仍要打开）；
3. 如果仍提示已损坏或无法验证，执行：
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Voucher Studio.app"
   ```

**自检依赖是否齐全**（本版应当只打印 `@rpath` 与系统框架，没有任何 `/Users/…` 输出）：

```bash
otool -L "/Applications/Voucher Studio.app/Contents/MacOS/voucher-studio" | grep -v @rpath
```
