# Voucher Studio 0.22.4

这一版把**应用内自动更新**接了进来：以后开新版本，不用再手动下载 dmg，App 里点一下就能更新。
另外统一了全仓代码排版（Prettier），并让 `format:check` 进入门禁——对界面没有可见变化。

> 如果你装的是 0.22.0 ~ 0.22.2，请先看 [0.22.3 的说明](0.22.3.md)（那几个版本的安装包引用打包机绝对路径，
> 换机打不开）；本版同样包含该修复。

## 本版做了什么

### 新增

- **应用内更新**：启动后自动检查新版本（`设置 → 通用 → 检查更新` 也可手动查），
  有新版本时显示版本号与更新说明，下载安装后提示重启。更新源是本项目的 GitHub Releases
  （`latest.json`），更新包经过签名校验，包内与安装版同样自包含。
  首次使用说明：更新功能从本版开始生效，**下一次发布**（0.22.5 及以后）才会在 App 内提示。

### 维护

- **全仓统一 Prettier 排版**：新增 `.prettierrc.json` / `.prettierignore`，`npm run format` / `format:check`；
  ESLint 接入 `eslint-config-prettier` 只管正确性。本轮重排 96 个文件（纯排版，无逻辑改动）。
- **门禁由「前端四门」升级为「前端五门」**：`format:check` 与 typecheck / lint / test / build 并列，
  CI 两处前端 job 都加了 Format check 步骤；新增契约测试锁住门禁接线，防止被静默摘掉。
- 文档类（`docs/`、`*.md`）与 shell 脚本不参与格式化，避免中文散文与表格产生无意义 diff。

## 安装与校验

本版**未做 Apple 公证**（没有开发者账号签名），首次打开需要：

1. 把 `Voucher Studio.app` 拖进「应用程序」；
2. 右键 → **打开**（或系统设置 → 隐私与安全性 → 仍要打开）；
3. 如果仍提示已损坏或无法验证，执行：
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Voucher Studio.app"
   ```

**自检依赖是否齐全**（本版应当没有任何 `/Users/…` 输出）：

```bash
otool -L "/Applications/Voucher Studio.app/Contents/MacOS/voucher-studio" | grep -v @rpath
```

如果这条命令打印出 `/Users/...` 开头的路径，说明你装的是旧版（0.22.2 及更早），请下载新版。

## 下载

- `Voucher.Studio_0.22.4_arm64.dmg`（Apple Silicon，macOS）
- `Voucher.Studio_0.22.4_arm64.app.tar.gz` + `.sig`（应用内更新的更新包，手动下载通常不需要）
- `latest.json`（应用内更新的版本清单）
- `sha256sums.txt`：下载后 `shasum -a 256 -c sha256sums.txt` 校验
