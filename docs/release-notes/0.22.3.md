# Voucher Studio 0.22.3

这一版是 **v0.22.2 的替代版**：v0.22.0 ~ v0.22.2 的安装包有一个会让人打不开 App 的问题，本版修好了，
并顺手做了一轮界面一致性收编（字号 / 圆角 / 间距 / 动效 / 骨架屏）和一张「数据健康」小卡。

## 重要：如果你装过 0.22.0 ~ 0.22.2

那几个版本的 `.app` 里，主程序引用的是打包机器上 OpenCV 的**绝对路径**（`/Users/apple/.local/...`），
`Contents/Frameworks` 是空的。换一台电脑打开会直接报 `Library not loaded`。
**请下载本版覆盖安装**（旧版可以删掉）。

## 本版做了什么

### 修复

- **安装包自包含**：OpenCV 依赖已收进 `Contents/Frameworks`，引用改为 `@rpath`，不再依赖打包机器；
  `scripts/release.sh` 增加了产物自包含硬校验，以后这类问题会在发版时被拦下。
- 日报 PDF 合计行右下角「N 张」与金额重叠 → 张数移到金额左侧 6mm，并加了不重叠的单测。
- 「相关凭证」建立关联时关键词输入框被说明框挤到 0 宽、搜索按钮看起来像两个 → 改为两行布局。

### 界面一致性（审计后的 U1–U5 收编）

- **字号统一为三档**（标题 / 正文 / 说明），并让设置里的「界面字号」真正整体缩放；角标不再低于 13px 可读下限。
- **清理旧视觉**：删掉 49 条零引用规则，移除旧紫渐变与 Fluent 蓝残留，颜色全部走语义令牌。
- **尺度枚举**：图标只保留 6 档尺寸，圆角/间距/控件高收进令牌，加了契约测试防止回潮。
- **设置页统一**：六个 Tab 的内联样式全部换成共享类，长页面结构一致。
- **加载骨架**：资料库列表与洞察页首次加载时显示骨架行，不再是一行「加载中…」。
- **动效令牌**：过渡时长统一走 `--motion-*`，并尊重系统「减少动态效果」。
- 列表缩略图改为 `contain`（90% 的凭证是长截图，之前 `cover` 会把中段裁掉）；筛选栏吸顶改用下边线。

### 新增

- **洞察页「数据健康」卡**：全库口径的「无图凭证 / 待识别 / 未被佐证」三项，每项可一键下钻到资料库对应筛选。
  资料库「缺项」筛选也新增了「无图凭证」。

## 安装与校验

本版**未做 Apple 公证**（没有开发者账号签名），首次打开需要：

1. 把 `Voucher Studio.app` 拖进「应用程序」；
2. 右键 → **打开**（或系统设置 → 隐私与安全性 → 仍要打开）；
3. 如果仍提示已损坏或无法验证，执行：
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Voucher Studio.app"
   ```

**自检依赖是否齐全**（本版应当没有任何 `/Users/…` 输出）：

```bash
otool -L "/Applications/Voucher Studio.app/Contents/MacOS/voucher-studio" | grep -v @rpath
```

如果这条命令打印出 `/Users/...` 开头的路径，说明你装的是旧版（0.22.2 及更早），请下载本版。
