## 1. a11y 五条（审计指南 §4.3）

### 1. 全流程键盘可达
- **操作**：不碰鼠标，只用 Tab / Shift+Tab / Enter / Esc / 方向键，依次完成：收件箱 → 打开资料库某行 → 改金额 → 保存 → 打印中心生成 PDF → 设置里切主题。
- **期望**：每个关键动作都能到达并触发；Tab 顺序与视觉顺序一致；看不到"只能点"的死角。
- **重点**：侧栏底部（版本行上方那一行）的**收起开关**用键盘能否操作（`aria-expanded` 是否随之翻转）、收起后 9 个图标能否凭 `title` 提示辨认；检视器里的就地编辑能否进出。

### 2. 焦点管理
- **操作**：① ⌘K 打开命令面板 → Esc 关闭；② 打开「删除重复凭证」二次确认 → Esc；③ 打开图片查看器 → Esc。
- **期望**：打开时焦点**进入内部**且 Tab 不会跑到背后的页面（焦点陷阱）；Esc 关闭后焦点**回到打开它的那个元素**；`:focus-visible` 的焦点环处处可见（2px + 5px 柔光环）。
- **不看**：鼠标点击时的焦点环（规范里故意只在键盘导航时显示）。

### 3. `aria` 与语义
- **操作**：开 VoiceOver（⌘F5），用 VO+→ 逐元素读一遍：侧栏入口、顶部工具栏、洞察页图表、打印中心格式分段、资料库筛选行。
- **期望**：控件有可读名称（不是"按钮"）；图表有 `role="img"` + 一句概述；异步结果（保存成功/识别完成 toast）会被播报。
- **记录**：读不出来的元素逐个记下来（这是最可能出问题的一条）。

### 4. 系统偏好三档
- **操作**：系统设置 → 辅助功能 → 显示，分别开启：
  ① **减少透明度** → 侧栏与工具栏应变为**不透明实色**（材质消失但不影响可读性）；
  ② **减少动态效果** → 过渡/悬停动效变即时（不该有残留的位移动画）；
  ③ **提高对比度** → 分隔线与次要文字明显加强（`--separator-strong` / `--label-secondary` 一档）。
- **期望**：三档**互相独立**，切回默认后观感复原；深色/浅色两套主题各看一遍。

### 5. 放大字号承受力（本项目用户视力不佳，属主需求）
- **操作**：设置 → 外观 → 界面字号切到**最大档**，然后逐页走：收件箱 → 资料库（含检视器）→ 洞察 → 打印中心 → 设置 → 打印预览弹窗。
- **期望**：**无截断、无横向溢出、无文字重叠**；长标签（如"打印与导出"侧栏项、"备份与恢复"）不被裁；表格类页面的列宽自适应。
- **已知风险**：洞察页的图表轴标签、打印中心的分段控件、侧栏 56px 图标栏在窄窗 + 大字号组合下最容易挤——重点看这三处。

## 2. 清单2 #48–50

### 6. 收件箱待办闭环（#48）
- **操作**：造一张待识别图片（导入）→ 回首页看"待识别"计数 → 点「开始识别」→ 把草稿全部复核 → 全部清零。
- **期望**：计数随动作变化且**与点进去看到的清单条数一致**（这正是审计 A-1/A-2 修的口径分叉）；"待核对"行在复核完消失；清零后只留一条"待办都清空了"细横幅，**不给已完成项留版面**。

### 7. 资料库双行列表 + 检视器（#49）
- **操作**：点任一行 → 右侧检视器出现大图与字段 → 改金额与摘要 → 保存；金额填 `12.34.56`；双击行；再试 ⌘⇧E。
- **期望**：保存后列表行同步更新并提示"已保存"；非法金额被拦下（红字提示，不写库）；**双击 = 展开编辑区并聚焦日期字段（v0.19 起不再跳独立编辑页）**；⌘⇧E 可切换展宽与收起；跨页选择集（勾选几行再翻页）保持勾选；**改一个字段后点另一行 / 点侧栏换页**，应先弹确认（默认「留在此页」，Esc 等同），选「放弃修改」才切走。

### 8. 洞察联动与材质（#50）
- **操作**：洞察页切「近 3 月」→ 观察趋势 / 月度透视 / 导出覆盖度三者是否同步；点月度透视任一行；把窗口拖到另一窗口或照片上方看侧栏与工具栏。
- **期望**：三个面板同窗口变化；点透视行 → 资料库**带精确筛选**且顶部有可清除的筛选标签（审计 A-* 的"下钻必须真过滤"）；侧栏与工具栏能看到 **Liquid Glass 模糊**；开「减少透明度」后变实色。

## 3. 批次 5 的目视项（定时器与监听）

### 9. 切页与热更不闪现
- **操作**：① 新建凭证页 → 点摘要输入框唤出联想下拉 → 立刻切走页面（不等 150ms）；② 回来看联想下拉是否还会闪一下或留下残留高亮；③ dev 模式下改一行无关代码触发热更，切系统深浅色看主题是否跟随正确。
- **期望**：无残留、无闪现、无"主题不再跟随系统"的现象（这正是批次 5 修的 `DescriptionInput` 延迟收起与 `config.ts` matchMedia 两处）。

## 4. v0.20 新增：OCR 自动填写观察（本版主题）

### 10. OCR 自动填写观察
- **操作**（都用真实图，别用合成图）：
  ① 导入 **2 张「两栏支付成功页」**（保险/缴费/公众号支付页，例如太平洋保险那张 `repro-cpic` 同型）；
  ② 导入 **1 张微信转账截图**（「转账-转给XXX」形态）；
  ③ 每张导入后看右栏与识别结果卡。
- **期望**：
  - **金额**：自动填且与票面一致——包括两栏页明细行「支付金额」那个数（**需 v0.20.1+**）；
  - **对方**：微信截图填成「转给」后的名字；两栏页填成收款方全称；**不应出现**「户名」「账号」「备注」这类界面词；
  - **日期**：自动填，允许与你的记账习惯差 1–3 天（已定口径，不算不通过）；
  - **摘要**：**始终为空**（等你手写）。
- **失败的样子**：金额空着或与票面不符；对方是界面词；摘要被自动写了——任一条出现即记不通过并留图。
