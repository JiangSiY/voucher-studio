# S0-03 凭据失效与重装（真实运行样例，部分）

- 执行时刻：2026-11-24T05:42Z（北京时间 13:42）
- 授权：取证授权单第 3 项（观察并截图「重启」后的凭据状态一次；不卸载、不删除条目、不改钥匙串权限）

## 实际发生

再次启动同一应用（同一 bundle，上一轮 `kill` 之后重启）：**同一把系统授权对话再次弹出**，说明「始终允许」未被授予、也没有被记忆——每次读取都要重新授权。

截图：[S0-03-重启后再现授权对话.png](./S0-03-重启后再现授权对话.png)

## 结论：**部分已证**

- 已证：重启后凭据访问**不会**无条件放行（授权对话再现，未静默通过）；「拒绝后重启即恢复访问」这条错误路径不存在。
- 未证：凭据「失效（过期/token 被清）」后的界面表现、以及「重装（删条目后重新写入）」后的状态——这两项都需要**真实的 WPS token 生命周期**，本机既没有该条目也没有真实授权，只能在真实运行 + 授权窗口里做。本单不卸载、不删条目，故不越界尝试。
