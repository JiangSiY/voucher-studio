# 机主手工补证指引（S0-02 字段值 / S0-04 入口截图）

> 面向：机主本人（唯一责任人）。助手不代输钥匙串密码、不代点界面，只负责启动构建与记录。
> 耗时：S0-02 约 3 分钟，S0-04 约 2 分钟，可分开做。
> 性质：**只读**。本页所有动作都不写业务库、不发真实 WPS 请求。
> 依据：本目录 [S0-01](./S0-01.md)/[S0-02](./S0-02.md)/[S0-03](./S0-03.md)/[S0-04](./S0-04.md)；代码行号取自 HEAD `673cf5b`。

## 0. 三条铁律（先读这一节）

1. **永远不要把登录钥匙串密码输入到聊天、文档、终端或任何输入框**——只有 macOS 自己的系统授权对话需要它。
2. 系统对话出现「始终允许」时，选「**允许**」（仅本次）：可回溯，下次读取仍会询问（S0-03 已证「重启后对话再现、不静默放行」）；选「始终允许」会把授权写进该条目的 ACL，后续静默放行，等于关掉了我们要验的那个提示。
3. **不要删除、移动、改名、覆盖** `~/Library/Application Support/VoucherStudio/voucher.db`（约 2.28 MB，大写、无连字符）及其 `-wal` 文件。

谁做什么：

| 角色 | 做什么 |
|---|---|
| 机主（本人） | 启动应用、在系统对话里输入钥匙串密码并选「允许」、抄下屏幕上的字段值、截图 |
| 助手 | 起开发构建、把一行命令贴进检查器、记录时间与画面；不接触密码、不点系统对话 |

## 1. S0-02：补两个字段值（约 3 分钟）

**目的**：把 `token_set` 与 `token_expires_at` 两个**界面返回值**记下来，补齐 [S0-02](./S0-02.md) 里「已证 OS 强制授权 / 未证字段值」的后半格。

**前置**：

- 应用在哪：发布版在 `target/release/bundle/macos/Voucher Studio.app`；本步需要**开发构建**（发布版没有显示这两个字段的界面，见下）。
- 要不要先备份库：**不需要**。这一步只读钥匙串，不碰业务库（`wps_credentials_status` 只读凭据状态）。
- 一个容易误会的地方：启动应用时弹出的「**Voucher Studio** 想要使用你储存在钥匙串的「**VoucherStudio**」中的机密信息」是应用在读**通用凭据库**（`crates/voucher-core/src/lib.rs:94`，`SecretStore::new("VoucherStudio")`），不是 WPS 凭据。WPS 凭据是**另一个** service `voucher-studio-wps`（`crates/voucher-core/src/services/wps_credentials.rs:16`），而本机这条**不存在**（[S0-01](./S0-01.md)）——所以读它**预期不会再弹密码框**，直接返回 `false` / `null` 就是答案。现场以实际画面为准。

**步骤**（助手起构建，机主只授权与读数）：

1. 助手在终端启动开发构建（`npm run tauri dev`；用 pnpm 则 `pnpm tauri dev`），等窗口出现。
2. 若弹出系统授权对话：机主输入登录钥匙串密码 → 选「**允许**」。（这一步是通用凭据库的授权，与 WPS 字段无关，但既然弹了就按第 0 节规矩处理。）
3. 助手在窗口里右键 →「检查元素」→ Console，粘贴并回车这一行：
   ```
   await __TAURI_INTERNALS__.invoke("wps_credentials_status")
   ```
   若右键没有「检查元素」，改用 `⌥⌘I` 再试；两者都没有则该构建读不到这两个字段 → 记「**未观测**」并停手，**不要**用别的方式猜值。
4. 屏幕会回一行 JSON，形如 `{ tokenSet: false, tokenExpiresAt: null }`。
5. 机主把这行里的两个值抄下来（助手可代为截图/复制这一行，但不得改动内容）。

**要记下来的东西**（字段名与值的格式）：

| 字段（代码名 / JSON 名） | 取值格式 | 预期 |
|---|---|---|
| `token_set` / `tokenSet` | `true` 或 `false` | `false`（本机无 WPS 凭据条目，[S0-01](./S0-01.md)） |
| `token_expires_at` / `tokenExpiresAt` | ISO-8601 UTC 时间串，或 `null` | `null` |

> 字段定义：`crates/voucher-core/src/services/wps_credentials.rs:23-26`（只暴露这两个字段，不提供读回 token 明文的命令）；前端映射 `src/api/client.ts:1290`。

**如果读到 `tokenSet: true`**：**不要**去找 token 明文，也不要导出；直接停手告诉助手——说明真实 WPS token 已在钥匙串里，S0-02 的结论要改写，需另走授权。

**做完交给助手**：上面那行 JSON 原文（或截图）+ 执行时刻（北京时间）。

## 2. S0-04：入口拒绝截图（约 2 分钟）

**目的**：记录「未授权时点「同步/读取」入口会被拒绝」的画面，闭 [S0-04](./S0-04.md) 那一格。

**先说清现状（这条会改变你的操作）**：发布版界面上**目前没有任何可点的 WPS 同步/读取入口**。整个 WPS 面板被开发开关挡着——`src/pages/DataPage.vue:74` 的 `isDev = import.meta.env.DEV && isTauri`、`:476` 的 `<section v-if="isDev" class="dev-w2">`（到 `:623` 结束，`ReauthBanner` 在 `:561` 也在里面）；发布构建里 `DEV=false`，所以这一整块不显示，唯一存在的 WPS 按钮组是开发构建里的 Mock 按钮（`:500-556`）。

也就是说：**缺的不是「截图权限」，而是真实的入口本身**（要 G1 放行后才有）。所以这一步能做出的诚实证据只有「无入口」，不是「入口被拒」。

**步骤**：

1. 打开 `target/release/bundle/macos/Voucher Studio.app`（发布版）。
2. 进左侧「数据页」，确认页面上没有「同步」「拉取」「读取」「台账同步」这类按钮。
3. 截图**整页**（包含侧边栏与页面标题，便于日后核对是哪一版）。
4. 记一句：`当前构建无可点的 WPS 同步/读取入口`。

**想看「被拒」的提示长什么样（非取证，不要当证据）**：只能在开发构建 + `VOUCHER_W2_MOCK=1` + 临时数据目录下，点「模拟创建（授权失效 400006）」，会显示「**需重新授权**」横幅与「WPS 授权已失效，当前仅可查看本机缓存。待处理 N 项已保留，恢复后不会自动重发。」（`src/components/wps/ReauthBanner.vue:45-46`、`:63`）。这是**合成文案**，只能说明界面文案形状，**不得**写成真实入口证据。

**做完交给助手**：整页截图 + 上面那句话 + 执行时刻。

## 3. 风险与边界

| 场景 | 规矩 |
|---|---|
| 需要重启 | 先 ⌘Q 完全退出应用再启动；不要同时开两份（两份进程会争同一把库） |
| 备份 | 本节两件事都**不需要**备份；也**不要**顺手移动/改名/删除 `voucher.db`、`voucher.db-wal` |
| 真实写入 | 助手不在场时**不得**点任何「同步/写入」；本页不要求任何写入动作 |
| S0-04 的禁区 | 只确认入口有无、截图；**不要**为了「让它拒一次」去跑真实同步或改启动参数连真实端点 |
| 钥匙串 | 不删条目、不改权限、不导出 token；密码只进系统对话 |
| 失败时 | 记「**未观测**」+ 当时画面 + 时间，不要反复重试（授权次数与限流次数本身也是证据） |
