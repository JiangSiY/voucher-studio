## 本轮修掉的缺陷

1. **深色打印预览白底白字**：`.print-area` 原只设白底、文字仍继承深色主题的
   `--label-primary`（`rgba(255,255,255,.92)`），预览内容完全不可见。
   现局部覆盖 `--label-* / --text* / --separator* / --surface*` 为 `--paper-*`。
2. **资料库空态只占左半屏**：未选中凭证时检视器隐藏，网格仍保留右栏。
   新增 `.split--empty`，列表卡独占整行。
3. **洞察卡片标题被挤成两行**：三卡同排后「存储占用」在窄卡里折行。
   标题 `white-space: nowrap`，右侧口径说明允许折行。
4. **真机反馈「主窗口左上标题太靠上」**：副标题原竖排在标题下方，把标题顶到工具栏上沿。
   改为标题 + 副标题同行、基线对齐后，标题回到 56px 工具栏垂直中线
   （1.15 倍字号实测 top 12px、中心 28px，原中心约 16px）。
