### W0-09 Link 对象格式（失败）

- update 02 的客户，值 `{"linkedRecordIds":["w"]}`。
- 结果：`code 400100，第三方服务错误：Internal error. Failed due to field: 客户`。
- 改回 `["w"]` 后成功。
- 结论：**统一使用 id 数组**；不要使用 `linkedRecordIds` 对象。

### W0-10 null 字段（失败）

- create 03 时 fields 中包含 `null` 字段。
- 结果：`code 400100，InvalidWpsBinaryData`。
- 去掉 null 后成功。
- 结论：**只发送有值字段**，不要发 `null`。

### W0-11 查询过滤（关键失败）

- 参数：`dbsheet_list_records`，`filter: {mode:"And", criteria:[{field:"应收单号", op:"Equals", value:"W0-AR-001"}]}`。
- 结果：返回表头前 3 条（`GY-000073`、`GY-000075`、`GY-000076`），**不是** W0-AR-001。
- 变体：`fieldId:"f"` 同样被忽略；`op:"Equals"` 未报错但无过滤效果。
- 补充：不传 `view_id` 时，09 默认视图（按电表 B1I）的过滤也未生效，返回全部电表。
- 结论：**`filter` 不可用于创建前单号预检**；方案 §4 的 `list_records(filter: 单号 Equals)` 链路不成立。
- 可用替代：`offset` 分页（已验证）、`page_size` 300/500、`view_id`（已验证生效，但仅静态条件，见 W0-12）。

### W0-12 `view_id` 过滤验证

- 参数：03 表默认视图 `view_id=E`（视图条件固定为「对方 Intersected BE」）。
- 结果：返回 5 条，全部 `对方=["BE"]`，证明 **`view_id` 过滤生效**。
- 限制：视图条件是**静态**的（该视图固定为「对方=BE」）；`get_schema` 只返回固定条件，未发现按请求参数动态过滤的能力；为每个新单号建一个视图不可行，MCP 白名单也没有建/改视图工具。
- 结论：`view_id` 可用于**固定范围**（如「11/1 后」）的拉取，但不能替代「任意单号 Equals 预检」；B 方案（按单号视图）不成立，预检仍需 A（分页扫描 + 本地索引），可用 `view_id` 缩窄扫描范围。

### W0-13 批量创建 50 条 11

- 结论：50 条批量可用；单次上限未继续往上探（生产批量上限按方案 ≤50）。

### W0-14 字符串金额

## 3. 关键结论

1. **可用**：6 表 create、update；Link 用 id 数组；ISO 日期；number/字符串金额；批量 10/50；09 创建。
2. **不可用**：`filter` 预检；`linkedRecordIds` 对象；`null` 字段；update 响应中的公式值（滞后）。
3. **必须应用侧保证**：09 `(电表, 期间)` 唯一；创建幂等；推送后重读；批量上限。
4. **W0/G0 结论：条件 GO（2026-11-19 用户决策）**。`filter` 预检失败、`view_id` 仅支持静态条件，方案 §4 改为 A（分页扫描 + 本地索引，`view_id` 仅缩窄范围）；50 条批量与字符串金额已验证；429/400006 用户接受“假 MCP 模拟 + 设计退避”作为 W0 通过条件（真实触发留灰度）。G0 允许 W1 的 **mock/本地**开发；真实 WPS 读取/写入仍须 S0 通过，W2 写入仍须 W0 GO + S0。

## 4. 预检方案结论（已确认，写入 §4/§6）

- **方案 A（推荐，必要）**：分页全表拉取 + 本地 SQLite 索引；按单号索引比对。成本：03 约 2 页（763/500），11 约 15 页（7056/500），02 约 2 页，06 约 4 页；每轮增量可按 `lastModifiedTime` 或日期窗口缩小。
- **方案 B（已验证不可行）**：`view_id` 过滤确实生效，但视图条件是静态的（默认视图固定「对方=BE」），MCP 白名单也没有建/改视图工具；无法为任意新单号动态建视图。B 只能用于固定范围（如「11/1 后」）的拉取，不能替代单号预检。
- 因此实际落地：A 为主；`view_id` 仅用于固定范围缩窄；如后续 WPS 提供可参数化视图或建/改视图动作，再评估 B。用户已确认 A + view 缩窄（m02234）。
- **更正注记（2026-11-20 评审）**：本节的「新建临时视图验证」思路**作废**——与「不得用 MCP 建/改视图」直接矛盾，且 MCP 白名单无建/改视图工具（W0-12 结论）。修正为：需要验证时**改用另一个已存在的视图**（只读拉取），不在应用内新建任何视图；`view_id` 缩窄同时**降级为未验证优化项**，不作为 G0/G1 门禁依赖——**A（分页全表 + 本地索引）是唯一预检路径**，评审批次后已固化到 `docs/评审修订清单-2026-11-20.md`。
