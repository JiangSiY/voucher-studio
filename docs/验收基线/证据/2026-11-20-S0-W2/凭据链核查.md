# WPS 凭据链核查（S0-01/02/03，2026-11-20 更新）

> 结论先行：本轮已新增 **WPS 专用、keyring-only** 的凭据入口，并有本地合成后端测试；**未写入真实 WPS token，未调用真实钥匙串**。S0-01/02/03 可由本地代码与测试证明“实现路径存在且不静默降级”，但“目标 Mac 上真实钥匙串写入/读取/删除、锁屏/重启/钥匙串不可用”仍须在 G1 授权后演练，不能以本轮证据代替签审。

## 1. 实现位置

| 项 | 位置 | 说明 |
|---|---|---|
| service 名 | `crates/voucher-core/src/services/wps_credentials.rs` 的 `WPS_KEYRING_SERVICE` | 固定 `voucher-studio-wps`，不复用通用 `SecretStore` |
| 写入/删除 | `WpsCredentialStore::set_token` / `delete_token` | 只写 token 与到期时间；不返回、不打印明文 |
| 请求注入 | `WpsClient::with_credentials`、`WpsCredentialProvider`、`auth_token()`；`services/wps_http.rs` 的 `LoopbackHttpTransport` | token 只作为 `initialize/call` 的 `auth` 参数；回环 HTTP 只放 `Authorization: Bearer`，不进 arguments、URL/query、正文、日志、备份；缺/过期凭据在建立连接前失败（0 请求） |
| 本地伪服务 | `MockTransport` 记录 `initialize_auths` 与 `MockCall.auth`；`DevW2Credentials` 返回 `synthetic-w2-dev-token` | 用于证明“取 token→认证调用”的链路，不发送真实请求 |
| 状态 | `WpsCredentialStore::status` → `WpsTokenStatus { token_set, token_expires_at }` | 对外只有两个字段，无 `get_token`/明文读取 API |
| 不可用 | `CoreError::KeyringUnavailable` | 钥匙串不可用时返回错误，禁止回落到文件后端 |
| API/UI | `crates/voucher-api/src/wps_credentials.rs`、`commands::wps_credentials_status` | 只暴露状态；Tauri 已登记 |

关键约束：`WpsCredentialStore::new()` 直接构造 `keyring::Entry`，**不读取** `CENTER_SECRETS_FILE`，也不包含文件后端分支。

## 2. 可复跑命令与结果

```bash
cd /Users/apple/Downloads/开发/voucher-studio
. "$HOME/.cargo/env"
cargo test -p voucher-core --lib --offline services::wps_credentials
# 8 passed / 0 failed

cargo test -p voucher-core --lib --offline services::wps::tests::token_is_passed_as_auth_and_not_arguments
# 1 passed：token 出现在 initialize/call 的 auth，不出现在 arguments

cargo test -p voucher-core --lib --offline services::wps::tests::credential_failure_stops_before_transport_call
# 1 passed：token 缺失/过期时 transport 0 调用

cargo test -p voucher-core --lib --offline services::wps_http
# 4 passed：回环白名单、Bearer 注入、缺/过期凭据零请求、不跟随重定向、错误体不回显
```

覆盖：

- `service_is_dedicated_and_does_not_use_generic_secret_store`：service 为 `voucher-studio-wps`，后端为 `keychain`；
- `center_secrets_file_env_does_not_change_backend_kind`：设置 `CENTER_SECRETS_FILE` 后仍是 `keychain`；
- `status_exposes_only_token_set_and_expiry_and_never_reads_file_backend`：内存后端下只返回 `token_set/token_expires_at`；
- `provider_returns_synthetic_token_for_dev_transport`：`DevW2Credentials` 只用于本地 Mock；
- `unavailable_keychain_errors_without_file_fallback`：钥匙串不可用返回 `KeyringUnavailable`，不创建文件；
- `delete_is_idempotent_and_clears_expiry`、`empty_token_rejected`。

## 3. S0-01/02/03 判定

| 项 | 本地结论 | 依据 | 剩余缺口 |
|---|---|---|---|
| S0-01 token 存储 | **实现已就位，待目标机取证** | 专用 service、keyring-only 构造、`set_token/delete_token`、客户端 provider 注入、8 例测试 | 未写入真实钥匙串；目标 Mac 的写入/读取/删除、重启持久化未演练 |
| S0-02 token 不可读回 | **实现已就位，待目标机取证** | 对外仅 `WpsTokenStatus`；无读取明文 API；token 仅进 auth、不进 arguments；8 例 + token 注入测试 | 日志/前端/配置全链路仍需目标机样例复核；本轮只证明入口结构 |
| S0-03 钥匙串不可用 | **本地实现可证，真实故障未演练** | `KeyringUnavailable` 分支；禁用文件回退；设置 `CENTER_SECRETS_FILE` 的测试仍为 keychain；token 缺失/过期在 transport 前停止 | 钥匙串锁定、拒绝访问、重装/迁移后的真实行为未演练；不改变 S0 未签状态 |

## 4. 明确未做

- 未写入真实 WPS token，未调用真实 WPS/HTTP；
- 未在目标 Mac 上执行钥匙串锁定/拒绝访问/重启演练；
- 当前 `WpsClient` 已能通过 `WpsCredentialProvider` 取 token 并以认证参数调用 `WpsTransport`；`DevW2Transport` + `DevW2Credentials` 证明“取合成 token → 认证调用”的本地链路，token 不出现在调用 arguments。2026-11-22 新增 `LoopbackHttpTransport`：只在回环地址上发 HTTP/1.1，token 走请求头，401/403 映射 `AuthExpired`，不跟随重定向，错误体自由文本不回显。**真实 HTTPS 端点、真实会话与重授权仍未实现**，因此不存在“真实 token → 真实 WPS”的端到端取证；真实 token 注入、TLS、会话与重授权仍须随 G1 实现补证。
- 未把本轮结果写成 S0 通过，S0/G1 结论仍由安全/运维与用户签审。
