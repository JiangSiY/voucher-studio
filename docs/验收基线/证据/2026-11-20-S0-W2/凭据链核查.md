# WPS 凭据链核查（S0-01/02/03，2026-11-20）

> 结论先行：**当前仓库没有 WPS token 的写入/读取/失效调用链**，因此 S0-01/02/03 不是“本轮 Mock 可补证”，而是“依赖后续实现”。本轮只做只读核查，未创建任何 WPS 凭据，未调用真实钥匙串或网络。

## 1. 核查命令与结果

```bash
cd /Users/apple/Downloads/开发/voucher-studio
grep -R "voucher-studio-wps\|wps_access_token\|wps_refresh_token" -n crates src src-tauri
# exit=1（无匹配）
```

```bash
sed -n '15,125p' crates/voucher-core/src/utils/crypto.rs
```

关键事实：

- `KNOWN_ALIASES` 只有 `ocr_api_key`、`webdav_password`、`backup_password`，没有 WPS token 别名（`crypto.rs:19-23`）。
- `SecretStore::new(service)` 默认走系统凭据库；但 `env_secrets_file()` 读取 `CENTER_SECRETS_FILE`，设置后 **静默切到 0600 文件后端**（`crypto.rs:29-56`、`:111-116`）。这与 S0-03“不静默降级”相冲突，若未来 WPS token 复用通用 `SecretStore::new` 会继承该行为。
- `inspect()` 只返回 `SecretStatus{alias,label,exists}`，不返回明文（`crypto.rs:94-107`）；但该接口尚未覆盖 WPS token 的 `token_set/token_expires_at` 字段。
- 全仓无 `voucher-studio-wps` service 名、无 WPS token 读写函数、无 WPS 登录/刷新/删除调用。

## 2. S0-01/02/03 判定

| 项 | 本轮结论 | 依据 | 缺口 / 前置 |
|---|---|---|---|
| S0-01 token 存储 | **不满足，依赖实现** | 无 WPS token 写入点；通用 Keyring 存在，但不是 WPS 专用 service | 需新增 keyring-only 的 WPS 凭据入口与写入路径 |
| S0-02 token 不可读回 | **部分依据，不能判定通过** | `inspect` 只回显 `exists`，但无 WPS token 结构/接口 | 需 WPS token 落地后验证命令、配置、日志、前端均只返回 `token_set/token_expires_at` |
| S0-03 钥匙串不可用 | **现有通用实现存在静默降级风险** | `CENTER_SECRETS_FILE` 可把 `SecretStore::new` 切到文件后端 | WPS 专用入口必须禁用文件回退，并补钥匙串不可用/重启失效演练 |

## 3. 本轮可复跑命令

