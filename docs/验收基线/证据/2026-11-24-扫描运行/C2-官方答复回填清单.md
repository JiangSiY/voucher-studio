# C2 官方答复回填清单与时限（2026-11-24）

> **地位**：本文把附条件 C2（`docs/验收基线/证据/2026-11-19-S0/检查表.md:65`）落成可执行的回填清单：谁来填、填在哪、几天内填、四种答复各怎么处置、什么话不许写。**不构成授权、不预先判定 Q1/Q2 已解**。
> **当前状态（写本文时的既成事实）**：Q1、Q2 均【待补】未答复（`70-官方核验清单.md:5`）；`approved_subject` 只能自述（`2026-11-24-扫描运行/实现证据.md:82`）；S0-05/06 维持**受限通过**（`检查表.md:51-52`）。

## 1. 时限与起算（先钉死这个，否则「5 个工作日」会被拖成无限期）

| 项 | 规则 | 依据 |
|---|---|---|
| 起算日 | **下一次 A2 授权真实运行完成日**（以状态库登记/执行结束时刻折算为 Asia/Shanghai 日期；折算口径属本文规定） | `检查表.md:107`、`签审决策表.md:104` |
| 期限 | 起算日之后 **5 个工作日**内书面回填 | 同上 |
| 「工作日」 | 不含周六、周日与中国法定节假日；遇节假日顺延 | 本文规定（口径统一用，避免争议） |
| 落盘时刻 | 不迟于第 5 个工作日 24:00（Asia/Shanghai） | 本文规定 |
| 逾期后果 | S0-05/06 维持「受限通过」；A4（G1）不因等待而推进；逾期本身要在开发日志挂账（`docs/开发日志.md:4313`） | `检查表.md:65`、`签审决策表.md:104` |
| 若一直未运行 | 期限不启动，但须在每次状态同步里写「C2 未回填，原因：无已授权真实运行」 | 本文规定 |

> 注意：C2 的期限**绑定的是「运行完成」而不是「官方答复到位」**。官方一直不答复时，仍要在 5 个工作日内把「已答复/未答复/答复含糊」的**事实**写进去，不能因为「没有答复」就不落盘。

## 2. 四种答复形态与处置（状态机）

| 形态 | 判定 | 回填动作 | 对判档的影响 |
|---|---|---|---|
| **A. Q1 确认「`fields` 在服务端裁剪」** | 有官方文档/工单号/邮件 + 日期 + 链接 | 70 清单 Q1 行把【待补】替换为「官方依据 + 日期 + 链接/工单号」；检查表 S0-06 待验项「`fields` 动作级支持」结项 | S0-06 的「`fields` 动作级」一项可移出待验；**Q2 未答则服务端隔离仍不成立** |
| **B. Q1 明确「不支持服务端裁剪」** | 同上形式 | 记「不支持」，并写清替代机制（视图/受限字段集/只读投影账号）或「无替代」 | 维持受限通过；扫描仍靠客户端整页拒绝；可评估 70 清单 §4 合成表退路（须签审人批准） |
| **C. Q2 确认「可按 `file_id` 授权」或「可为该次取证单建只读主体」** | 官方权限模型说明 + **可复现配置步骤**（截图/录屏由签审人执行） | 70 清单 Q2 行替换【待补】；`签审决策表.md` §0/§5 同步；入口证据 §11 补一条 | 这是 C2 唯一可能把 S0-06 从「部分验证+不可证」推向「已证」的路径，**但仍需实际按步骤配置并留证据**，仅有「支持」声明不算 |
| **D. Q2 答「不支持/无法确认」** | 同上形式 | 记「不可证」，写明官方原话要点 | 维持「部分验证 + 不可证」；A2 继续逐次签批；不解除任何门禁 |
| **E. 答复含糊/答非所问/仅口头** | 不满足「可接受的证据」要求 | 记「答复不成立」，把原话要点与不成立理由写下，并记催办日期 | 等同未答复，**不得**把【待补】改成「已解」 |

「可接受的证据」标准（照抄 `70-官方核验清单.md:17`、`:28`，不得放宽）：官方文档中该动作的参数与响应说明（含版本/日期），或官方工单/邮件答复（附工单号）；**本机插件 schema、WPS REST 文档、本地白名单均不算**（Q1）；官方权限模型说明 + 可复现配置步骤（Q2）。

## 5. 禁止事项

1. **不得**把本机插件 schema、WPS REST 文档、本地白名单写成「官方依据」（`70-官方核验清单.md:17`）。
2. **不得**把入口侧目标/主体绑定（`approved_file_id`/`approved_subject`）当作服务端隔离证据（`实现证据.md:82`：Q2 仍记「部分验证 + 不可证」）。
3. **不得**在答复未到位时把【待补】直接改成「已解」；只能改成「未答复」并保留待补属性。
4. **不得**用 C2 回填写 S0-07/08 的真实部分（那是 C4 的范畴）或 C5（写入与一致性不在本签内）。
5. **不得**因为 C2 部分收口就调整 `transport=mock` 默认或放开 G1（C1 原文：本签不构成 G1）。
