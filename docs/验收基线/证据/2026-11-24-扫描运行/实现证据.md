## 2. 离线验收

| 场景 | 结果 |
|---|---|
| 未签模板 `--check` | `P2_E_GRANT`（缺 `approved_by`），exit 2，零请求、不建库 |
| 回环端点在未加 flag 时 | `P2_E_GRANT`（只允许本机回环），exit 2 |
| 合成签署副本 `--check --allow-real-endpoint` | `{"check":"scan-preflight","required_reads":44,"max_reads":74,"max_total_requests":80,"sheets":[1,2,3,4,5,6,14],"pages":{"1":2,"14":1,"2":1,"3":8,"4":8,"5":1,"6":1}}`，exit 0，**零发网、未建状态库** |
| `--transport offline` 执行一次 | `P2_E_PROTOCOL_PENDING`，exit 1；状态库登记 `A2-SCAN-20261124-01 | xujZ…rW` |
| 同授权再执行 | `P2_E_ALREADY_USED`，exit 1（运行级只消费一次） |
| 外部 `--cursor Cj` | exit 2，「扫描运行不允许 --cursor/--page」 |
