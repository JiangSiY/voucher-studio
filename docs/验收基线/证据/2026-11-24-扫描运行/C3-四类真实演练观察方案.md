# C3 四类真实演练观察方案与记录表（2026-11-24）

> **地位**：本文只把附条件 C3（`docs/验收基线/证据/2026-11-19-S0/检查表.md:66`）落成「怎么观察、怎么记、记到什么程度算数」，**不修改 C3 原文、不构成授权、不批准任何人现在发起真实请求**。执行真实运行必须另持已签署的 A2 授权单（模板见 [`A2扫描级授权-v2-模板.md`](./A2扫描级授权-v2-模板.md)）。
> **本轮零请求**：本文编写期间未发起任何 WPS 请求；文中代码位置均为静态阅读结果，`--check` 证据取自本地二进制（`offline` 传输）。

## 1. 三级记录口径（先定口径，再谈证据）

| 级别 | 定义 | 是否可改变 S0-12 判档 | 写法 |
|---|---|---|---|
| **自然出现** | 在已授权真实运行中，由服务端/网络自发产生，未被任何人为构造 | **是**（唯一可改判档的级别） | `自然出现` |
| **受限演练** | 人为施加但**不增加请求数**（如物理断网、删除本地 token 文件后不再重发） | 默认**不计入**；是否计入须由签审人另文决定 | `受限演练（不计入自然出现）` |
| **未观测** | 该次授权运行中未出现 | 否，且**不得改写为通过** | `未观测` |

三条硬规则（C3 原文的直接落法）：

1. **自然出现即记录并停止**——一旦命中，当场停止，不续跑、不重试、不在同一授权单内再发一次。
2. **不得为凑证据刷请求**——禁止循环重试、并发轰炸、反复通断网络、故意吊销权限等方式制造现象。
3. **未出现写「未观测」**——不得用「本地已有合成用例」替代，也不得把 Mock/合成断言当真实演练（`签审决策表.md:80` 已明写「不得以 Mock 代替」）。

## 2. 两个入口必须先分清（否则记录会串档）

| 入口 | 命令 | 失败后是否重试 | 依据 |
|---|---|---|---|
| **扫描入口**（7 表两遍全扫） | `wps-p2-scan` | **不重试**：`transport.call(...)?` 直接上抛，无 `is_retryable` 分支、无会话重建、无退避 | `crates/voucher-core/src/services/wps_p2.rs:1777-1784` |
| **单页入口**（一张表一页） | `wps-p2-read` | 读取预算 ≤3 次（含首发与重建重发）；仅 `RateLimited\|Timeout\|Server` 可重试；退避 1s；退避期间窗口到期即停 | `wps_p2.rs:131-134`（`is_retryable`）、`:1233-1240`、`:1326-1340`、`:1144`（`max_attempts` 默认 `P2_MAX_READ_ATTEMPTS`） |

> 因此记录表里**必须写明入口**：同一现象在两个入口的期望行为不同（例如 429 在扫描入口「一次即停」，在单页入口「≤3 次尝试」）。把两者混记会得出错误结论。

## 3. 四类逐一：触发面、代码路径、期望、记录、禁区

### D1 token 移除

- **触发面**：本地凭据文件不可读/为空/多行，或运行中取不到 token。
- **代码路径（两条，语义不同，必须分开记）**：
  - **路径 A（CLI 层，推荐记为「受限演练」）**：`read_token_file`（`crates/voucher-cli/src/main.rs:148-162`）在**解析授权单之前**执行；失败即 `fail(2, ...)`（扫描入口 `main.rs:652-663`、单页入口 `main.rs:302-316`）。→ **零请求、不建状态库、不消费授权**（`consume` 在 core 的 `run()` 内，尚未被调用）。
  - **路径 B（run 内）**：`credential.access_token()` 返回空 → `P2_E_CREDENTIALS`（`wps_p2.rs:1727-1735`）。注意次序：`consume` 在 `:1720`，**先于**取 token → **授权已被消费**，该 grant 作废。
- **期望**：requests = 0；路径 A 状态库无登记，路径 B 状态库已登记且 `P2_E_ALREADY_USED` 阻止重跑。
- **必须记录**：路径 A/B、退出码、码值、状态库是否已登记、requests 计数。
- **禁区**：不得为演练删除 token 后在同一窗口内反复删/放再重跑；不得把路径 B 造成的授权作废当成「演练成功」后申请补签同一 `grant_id`。

### D2 400006（授权失效/无权）

- **触发面**：真实读取时服务端返回 400006。
- **代码路径**：`classify_http_status(400006) → P2Error::AuthExpired`（`wps_p2.rs:980`）→ 码 `P2_E_AUTH`（`:117`）；扫描入口直接上抛停止（`:1777-1784`）；单页入口 `is_retryable()==false`（`:133`）→ 立即返回并留一条审计（`:1337-1340`）。
- **期望**：立即停止、**不重试**、无后续请求、不写 30 分钟冷却（该冷却属 W2 入口，见 D3 澄清）、退出码非 0。
- **必须记录**：失败时的表号/页号、`actions` 计数、`termination`（是否已发 `DELETE`、远端是否确认）、是否留有可续传队列（当前**无续传实现**，记「未实现」）。
- **禁区**：**不得为造 400006 而手动吊销权限或改坏 token**——C4 明确「重授权 UI 与查看范围二次确认实现前不做真实失效人工演练」（`检查表.md:67`）。本类只能**自然出现**。

### D3 429（限流）

- **触发面**：服务端限流。
- **代码路径**：429 → `P2Error::RateLimited`（`wps_p2.rs:982`、`:994`）→ 码 `P2_E_RATE`（`:119`）；扫描入口**一次即停**；单页入口按 `is_retryable` 退避 1s、至多 `max_attempts`（3）次，退避期间窗口到期 → `P2_E_WINDOW`（`:1326-1335`）。
- **期望**：扫描入口请求数不再增长、当场停止；单页入口 `attempts_used ≤ 3`；同一窗口内不得再发新批次。
- **口径澄清（重要，防止把两套冷却混为一条证据）**：`wps.rate_limit_until` + 30 分钟冷却（`crates/voucher-core/src/services/wps_w2.rs:341-342`、`:444-451`）属 **W2 台账同步入口**，S0-08 的「转 30 分钟」口径针对该入口；**P2 扫描/单页入口没有 30 分钟冷却机制**。C3 记录里若把 W2 冷却时延写成 P2 的 429 处置证据，即为串档。
- **必须记录**：入口、`attempts_used`、是否进入退避、是否因窗口到期停止、码值。
- **禁区**：不得并发轰炸或循环重试制造 429；单页入口重试次数已由代码锁死，不得改配置「多试几次」。

### D4 断网

- **触发面**：本地断网、DNS 失败、TLS 失败、连接超时。
- **代码路径**：传输错误分类为 `P2_E_TIMEOUT` / `P2_E_TLS` / `P2_E_HOST` / `P2_E_SERVER`（`wps_p2.rs:113-121`）；扫描入口直接停；单页入口中 `Timeout`/`Server` 可重试（`:133`），`Tls`/`Host` 不重试。
- **期望**：停止并记录失败页；失败页不计入成功读取；扫描入口零重试，单页入口 ≤3 次。
- **允许动作**：可**物理断网**（不增加请求数），但必须记为**受限演练**，默认不计入自然出现。
- **必须记录**：错误分类（TLS/DNS/超时/连接拒绝）、失败页、是否重试、`actions` 计数。
- **禁区**：不得为凑「重试路径」反复通断网络制造多轮请求。

## 5. 什么条件下才能申请改 S0-12 判档

全部满足才可提交（缺一条即维持「受限通过」，`检查表.md:51-52`、`:58`）：

1. 四类**各有**一条完整记录（自然出现，或明确写「未观测」）——「未观测」本身也算记录完整，但**不改判档**。
2. 每条记录都有：入口、码值、退出码、该次请求数、是否重试、是否停止、证据路径。
3. 出现即停的证据（时间线与 `actions` 计数一致，无「停后又发」的空档）。
4. 全程无「为凑证据」的重复运行（授权单 `grant_id` 一次性，状态库可证每次只消费一次）。
5. 记录人与签批人一致（本人），并在证据里写明「本次为自然出现，非人为构造」。

单类达标只改单类：例如只有 429 自然出现，则只申请把「429」从待验移出，S0-12 整体仍记「受限通过」。

## 6. 与其他附条件的边界

- **C2**：本文不回答服务端字段裁剪/单副本隔离，记录里不得出现「因 429 行为符合预期，故服务端权限已证」这类推论。
- **C4**：D2（400006）在重授权 UI 落地前**不得人为演练**；本文不构成对该 UI 的验收。
- **C5**：四类演练全部发生在**只读**扫描，不产生任何 `create`；**不得**被引用为 C5 ①②③ 证据，也不解除写入阻断（`检查表.md:68`）。
