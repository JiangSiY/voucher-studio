## 1. 命令与边界

```
voucher-cli wps-p2-read --grant <授权.json> [--state <状态.db>] [--check]
                        [--transport offline|loopback-tls --trust-root <ca.der>]
```

| 约束 | 实现方式 | 证据 |
|---|---|---|
| 无法指向真实 WPS | 端点主机白名单：`p2-local.test`/`localhost`/`127.0.0.1`；`loopback-tls` 把主机固定解析到 `127.0.0.1:<port>` | 场景 5：`example.com` → `P2_E_GRANT`，退出码 2 |
| 默认零发网 | 默认 `--transport offline` → `UnavailableP2Transport`，任何调用本地返回 `P2_E_PROTOCOL_PENDING` | 场景 2 |
| 不读真实凭据 | 固定合成 token（`synthetic-p2-token`），不接钥匙串、不接受外部 token | 代码 `SyntheticCredential` |
| 单次授权 | `SqliteP2State` 在发网前登记；跨进程/重启防重 | 场景 2→3 |
| 预检不发网 | `--check` 只做 `P2Grant::preflight`，不建状态库、不发请求 | 场景 1 |
| 本地 TLS 需显式 CA | `loopback-tls` 缺 `--trust-root` 直接参数错误，不登记状态库 | 场景 6 + 测试 4 |

## 2. 授权单 JSON（与 A2 授权单字段对应）

```json
{
  "grant_id": "A2-CLI-EVIDENCE-01",
  "approved_by": "安全/运维（示例）",
  "endpoint": "https://p2-local.test:8443/mcp",
  "file_id": "dbsheet_replica_001",
  "approved_file_id": "dbsheet_replica_001",
  "sheet_id": 3,
  "fields": ["A", "B"],
  "window_start": "…",
  "window_end": "…",
  "approved_subject": "tenant-a/reader",
  "page_size": 50,
  "max_total_requests": 8,
  "terminate_allowed": true
}
```

字段为空（`fields: []`）会被拒：CLI 要求逐列批准，不接受「全部字段」。

## 3. 离线验收（实跑，2026-11-23）

命令（窗口按当天 UTC 动态生成，仅本机执行）：

```
./target/debug/voucher-cli wps-p2-read --grant $T/grant.json --check
./target/debug/voucher-cli wps-p2-read --grant $T/grant.json --state $T/state.db
# 重复执行同上
./target/debug/voucher-cli wps-p2-read --grant $T/bad.json --check          # endpoint=example.com
./target/debug/voucher-cli wps-p2-read --grant $T/grant.json --state $T/s2.db \
    --transport loopback-tls                                               # 缺 --trust-root
```

| # | 场景 | 退出码 | 输出（节选） | 状态库 | 发网 |
|---|---|---|---|---|---|
| 1 | `--check` 合法授权 | 0 | `{"ok":true,"check":"preflight","grant_id":"A2-CLI-EVIDENCE-01","host":"p2-local.test","sheet_id":3,"page_size":50}` | 未创建 | 0 |
| 2 | offline 执行（首次） | 1 | `P2_E_PROTOCOL_PENDING: 真实 HTTPS 会话协议尚未取得可核实依据，P2 传输未接线` | 已登记 | 0 |
| 3 | 同授权再次执行 | 1 | `P2_E_ALREADY_USED: 该授权已在执行状态库登记消费，不能再次启动` | 不变 | 0 |
| 4 | 状态库内容 | — | `A2-CLI-EVIDENCE-01｜dbsh…01｜<window_end>`（file_id 脱敏） | 1 行 | 0 |
| 5 | 非回环端点 | 2 | `P2_E_GRANT: CLI 只允许本机回环端点（p2-local.test/localhost/127.0.0.1），拒绝 example.com` | 未创建 | 0 |
| 6 | `loopback-tls` 缺 CA | 2 | `错误：loopback-tls 需要 --trust-root <测试 CA DER>` | 未创建 | 0 |

## 7. 本机 HTTPS 成功链路（2026-11-23 第二轮实跑）

命令（独立 CLI 进程 + 隔离状态库 + 合成授权 + 本机 rustls/python 测试服务，证书与 CA 均为仓库夹具）：

```
./target/debug/voucher-cli wps-p2-read --grant $T/grant.json --state $T/state.db \
    --transport loopback-tls --trust-root crates/voucher-core/tests/fixtures/p2-tls/ca.der
# 同授权 + 同状态库再跑一次
```

| 步骤 | 退出码 | CLI 输出（脱敏） | 服务端动作计数 |
|---|---|---|---|
| 合法首屏读取 | 0 | `{"ok":true,"transport":"loopback-tls","sheet_id":3,"record_count":1,"attempts_used":1,"actions":{"initialize":1,"notify":1,"read":1,"terminate":1,"total":4},"termination":"远端终止已确认"}` | 4：`POST /mcp`×3 + `DELETE /mcp`×1 |
| 同授权重启 | 1 | `P2_E_ALREADY_USED: 该授权已在执行状态库登记消费，不能再次启动` | **仍为 4（新增 0）** |
| 状态库（脱敏） | — | `A2-CLI-HTTPS-EVIDENCE-01｜dbsh…01｜<window_end>` | — |

自动化回归（`tests/p2_read_cli_https.rs`，2 例）：

| 用例 | 断言 |
|---|---|
| `cli_runs_one_legal_read_over_local_https_then_blocks_replay` | 退出 0；`actions` 四项各 1、`total=4`；服务端 4 次请求且第 4 次为 `DELETE`；同授权重放 `P2_E_ALREADY_USED` 且服务端计数不变 |
| `cli_check_does_not_consume_grant` | `--check` 不建状态库、服务端 0 请求；随后同授权仍可真正执行一次（4 次请求） |

注意：**`--check` 不消费授权**，但**默认 `offline` 执行仍会在发网前登记消费**（`P2_E_PROTOCOL_PENDING` 后同一授权不可再用），日常预检请用 `--check`。
