## 1. 命令与边界

```
voucher-cli wps-p2-read --grant <授权.json> [--state <状态.db>] [--check]
                        [--transport offline|loopback-tls --trust-root <ca.der>]
                        [--transport https --allow-real-endpoint --token-file <t>]
```

| 约束 | 实现方式 | 证据 |
|---|---|---|
| 默认无法指向真实 WPS | 端点主机白名单：`p2-local.test`/`localhost`/`127.0.0.1`；`loopback-tls` 把主机固定解析到 `127.0.0.1:<port>`；`https` 真实端点模式须 `--allow-real-endpoint` + `--token-file` 双开关（§8） | 场景 5：`example.com` → `P2_E_GRANT`，退出码 2；§8.2 四例 |
| 默认零发网 | 默认 `--transport offline` → `UnavailableP2Transport`，任何调用本地返回 `P2_E_PROTOCOL_PENDING` | 场景 2 |
| 默认不读真实凭据 | `offline`/`loopback-tls` 固定合成 token（`synthetic-p2-token`）；`https` 只从显式 `--token-file` 读一行，不读钥匙串/环境变量/argv | 代码 `SyntheticCredential` / `FileTokenCredential`；§8.2 |
| 单次授权 | `SqliteP2State` 在发网前登记；跨进程/重启防重 | 场景 2→3 |
| 预检不发网 | `--check` 只做 `P2Grant::preflight`，不建状态库、不发请求 | 场景 1 |
| 本地 TLS 需显式 CA | `loopback-tls` 缺 `--trust-root` 直接参数错误，不登记状态库 | 场景 6 + 测试 4 |

## 8. 真实端点模式（2026-11-23 晚，默认关闭）

### 8.1 三重开关

| 条件 | 不满足时的行为 |
|---|---|
| `--transport https` | 否则仍走 `offline`（零发网）或 `loopback-tls`（仅回环） |
| `--allow-real-endpoint` | **缺此项直接退出 2**，错误写 stderr：「https 真实端点模式默认关闭：须显式加 --allow-real-endpoint 才放行」 |
| `--token-file <路径>` | 缺此项退出 2；文件不存在/为空/多行均退出 2；错误只描述文件，不回显内容 |

补充约束（与既有 A2 条款一致，未放宽）：

- 授权单 `endpoint` 主机非回环时，只有在带上 `--allow-real-endpoint` 时才会被 `p2_grant_from_value` 接受；不带则仍是「只允许本机回环端点」的拒绝。
- 传输层仍校验「请求端点 == 授权端点」，不一致即 `P2Error::Endpoint`；`Policy::none()` 不跟随重定向，证书与主机名默认严格校验（如需固定测试根可显式 `--trust-root`）。
- 执行模式仍必须 `--state <db>`：真实调用同样要在发网前登记 `grant_id`，一次消费后不可重放。
- 读取预算（`initialize ≤2` / `notify ≤2` / `list_records ≤3` / `DELETE ≤1` / 整场 ≤8 / 窗口 ≤15 分钟）与输出脱敏规则完全不变。

`--check` 在真实端点模式下同样只做本地预检：输出 `real_endpoint: true`、`credential_file: true`，但**不含 token**，也不创建状态库。

## 11. 分页游标诊断（2026-11-23，零新增真实调用）

- 现象：第二发 27 条 vs 插件同参数 50 条。
- 根因：`offset` 是不透明**字符串游标**（首屏 `""`），CLI 之前发数字 `0`。
- 证据：插件 `offset` 空 → 50 条 + 游标 `BF`；`offset="BF"` → 10 条（共 60 行）。
- 修复：CLI/入口改为发 `"offset": ""`，并把响应 `data.detail.offset` 作为 `cursor` 输出。
- 回归：`p2_https_wps_envelope_cursor_is_reported`（断言 `cursor=VW` 且请求体为 `"offset":""`）；`services::wps_p2` 40 例。
- 待闭环：再签一发授权单确认 CLI 返回 50 条。
