## 2. 零请求对照表

「请求」= 传输层 `initialize` + `call` 的实际调用次数（计数器在测试桩内）。

| 场景 | 结果码 | 初始化 | 调用 | 用例 |
|---|---|---|---|---|
| 入口默认关闭 | `P2_E_CLOSED` | 0 | 0 | `p2_default_gate_is_closed_and_issues_zero_requests` |
| 授权缺签批人 | `P2_E_NOT_APPROVED` | 0 | 0 | `p2_rejects_unapproved_or_write_actions` |
| 目标 `file_id` 与签批不符 | `P2_E_TARGET` | 0 | 0 | `p2_denies_unapproved_target_before_any_request` |
| 请求表号不在签批范围 | `P2_E_SCOPE` | 0 | 0 | `p2_denies_sheet_outside_grant_and_response_field_outside_grant` |
| 窗口外（早于/晚于） | `P2_E_WINDOW` | 0 | 0 | `p2_denies_expired_window_and_unapproved_or_mismatched_subject` |
| 凭据主体不符 / 无法核对 | `P2_E_SCOPE` / `P2_E_SCOPE_PENDING` | 0 | 0 | 同上 |
| 写动作（`create_records`/`update_records`） | `P2_E_ACTION` | 0 | 0 | `p2_rejects_unapproved_or_write_actions` |
| 未知动作（如 `delete_records`） | `P2_E_ACTION` | 0 | 0 | 同上 |
| 真实传输未接线 | `P2_E_PROTOCOL_PENDING` | 0 次发网 | 0 次发网 | `p2_unwired_https_transport_fails_before_sending` |
| 证书不可信 | `P2_E_TLS` | 1 | 1 | `p2_tls_and_hostname_failures_stop_without_follow_up_requests` |
| 主机名不匹配 | `P2_E_HOST` | 1 | 1 | 同上 |
| 服务端重定向 | `P2_E_REDIRECT` | 1 | 1 | `p2_redirect_is_not_followed`（断言无第二次请求、args 无 `Location`） |
| 响应含未授权字段 | `P2_E_SCOPE` | 1 | 1 | `p2_denies_sheet_outside_grant_and_response_field_outside_grant`（请求已发出，返回前拒绝，不落库） |

> 说明：请求侧范围越界为零请求；**响应侧**字段越界必然发生在一次请求之后，因此只承诺「不返回、不落库」，不承诺零请求。

## 3. 合法读取全链路（正面对照）

`p2_legal_read_runs_full_chain_with_scope_derived_args`：

- 授权：`https://wps.example.test/mcp`、`file_id=dbsheet_replica_001`、表 3 字段 `{A,B,C}`、窗口 `2026-11-22T10:00Z–12:00Z`、主体 `tenant-a/reader`。
- 结果：1 次初始化 + 1 次调用；`args = {file_id, sheet_id:3, offset, page_size, fields:["A","B","C"]}`；返回记录只保留授权字段；`total` 透传。
- 断言：`args` 文本不含合成 token；`attempts_used=1`。

## 4. TLS、重定向、会话与重试

- `P2TlsPolicy` 默认 `verify_certificates=true`、`verify_hostname=true`、`https_only=true`、`follow_redirects=false`；关闭任一项即 `P2_E_TLS`/`P2_E_HOST`/`P2_E_REDIRECT`。
- `classify_http_status`：3xx → `P2_E_REDIRECT`（不跟随）；401/403 → `P2_E_AUTH`；404 → `P2_E_SESSION`；429 → `P2_E_RATE`；5xx → `P2_E_SERVER`。
- `classify_connect_hint`：含 hostname/subject 的提示归 `P2_E_HOST`，其余 TLS 握手失败归 `P2_E_TLS`；只归类，不回显原始错误文本。
- 混合路径（`p2_retries_are_capped_and_session_expiry_reinitializes_once`）：会话过期 → 重建一次（不计入尝试）→ 超时 → 5xx → 成功；共 4 次调用、`attempts_used=3`、初始化 2 次。全失败时 3 次调用后停止，不越上限。
- 审计行（`p2_audit_line_masks_file_id_and_never_carries_token`）：`p2 action=dbsheet.list_records host=… file=dbsh…01 sheet=3 outcome=… attempts=…`，不含完整 `file_id` 与 token。
