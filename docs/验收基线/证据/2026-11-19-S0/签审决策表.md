## 5. S0-07 授权失效口径（拟议，**待确认**）

1. **可见范围**：授权失效时，用户仍可查看其原本有权访问的**本机**列表、详情与待处理状态；界面标注「需重新授权」与**最后同步时间**。
2. **暂停项**：远程刷新、提交、队列续传一律暂停；不发起任何 WPS 请求。
3. **恢复后**：可恢复读取；待写项须**重新预检并经用户确认**后才可写入，不自动续传。
4. **结果不明项**：继续人工核对（对照批次与远端记录），不因授权恢复自动重发。
5. 待确认点：哪些列表/详情允许离线查看、是否需要二次确认弹窗；**重授权 UI、队列续传、红点仍未实现**，本地仅证到「停批 + 提示 + 不重发」。

## 6. S0-08 冷却口径（拟议，**待确认**）

1. **共用截止时间**：同一授权范围内由 Voucher Studio 发起的读写共用同一冷却截止时间（`wps.rate_limit_until`，30 分钟，RFC3339 秒级 UTC）。
2. **桌面与网页**：若二者共用应用后端，则执行同一截止时间；**独立 WPS 网页的限额行为保留待验证**，不假设一致。
3. **冷却期**：允许查看本机已有数据，不发起远程刷新或新批次；再次点击为零请求（已本地实测）。
4. **人工转交**：建议由**用户**接手；先核对批次与结果不明项，再决定是否手工录入，不由系统自动重试。
5. 待确认点：冷却触发范围（入口/错误类型/跨进程）、人工转交责任人；**真实 429 若未自然观察到，保留待验，禁止通过刷请求触发**。

## 7. C5 条款（拟议必验项）

1. **0 次 create 是必验项**：字段一致性证据不足时一律阻断写入；阻断记录必须同时包含①扫描诊断、②入口的阻断结果、③传输层 `create = 0`。
2. **不足以证明字段一致**：分页完整、总数稳定、ID 无重复都不构成字段级一致性证据；G1 签署本身也不替代证据。
3. **入口与证据**：拟放行写入入口须先 `pull_all_history_strict`，被快照门阻断时**不得进入预检/写入**；本地 Mock 已按此接线（`run_strict_mock_batch`，桌面场景 `c5_blocked`）。
4. **本地实测（2026-11-22）**：`pull.complete=true`、`snapshot_verified=false`、`writes_blocked=true`、原因 `WPS_E_PULL_SNAPSHOT_UNVERIFIED`、11 表扫描、`create=0`、库内 `runs=0 / intents=0 / scans=11`；同入口正常批次对照 `create=2`，证明计数能捕获 create。证据见 [`入口证据.txt`](../2026-11-22-C5-入口阻断/入口证据.txt)。
5. **签审问题**：确认真实副本 C5 的**验收入口**（用哪个写入口跑）、**取证方式**（如何留 0 次 create 轨迹）与**证据归档位置**；真实副本复验须在专项授权后执行。
6. **边界**：上述为本地 Mock 入口证据，不等于真实副本 C5 已验；真实副本 C5 继续由写入阻断保护。
