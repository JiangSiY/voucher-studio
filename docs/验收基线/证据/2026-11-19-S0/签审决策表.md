## 4. C5 条款（拟议必验项）

1. **0 次 create 是必验项**：字段一致性证据不足时一律阻断写入；阻断记录必须同时包含①扫描诊断、②入口的阻断结果、③传输层 `create = 0`。
2. **不足以证明字段一致**：分页完整、总数稳定、ID 无重复都不构成字段级一致性证据；G1 签署本身也不替代证据。
3. **入口与证据**：拟放行写入入口须先 `pull_all_history_strict`，被快照门阻断时**不得进入预检/写入**。
4. **本地实测（2026-11-22）**：桌面场景 `c5_blocked` 走 `run_strict_mock_batch`；11 表扫描完成后因快照不可验证而阻断（`WPS_E_PULL_SNAPSHOT_UNVERIFIED`），`create=0`、写入意图 `intents=0`、库内 `runs=0 / scans=11`；同一开发 API 的 normal 分支对照 `create=2`，证明计数器能捕获创建请求。证据见 [`入口证据.txt`](../2026-11-22-C5-入口阻断/入口证据.txt)。
5. **真实副本 C5 验收入口**：必须从**拟放行的写入入口**触发，并在同一轮运行归档三项证据；不得单独测扫描函数，也不得引用 C6 的零创建轨迹替代。
6. **边界**：上述为本地 Mock 入口证据，不等于真实副本 C5 已验；真实副本 C5 继续由写入阻断保护，待专项授权复验。

### 4.1 P2 只读入口离线验证（2026-11-22）

- **实现**：`crates/voucher-core/src/services/wps_p2.rs`——默认 [`P2Gate::Closed`]；授权参数（签批人、端点、`file_id`、表/字段、执行窗口、授权主体）发网前逐项预检；动作只允许 `dbsheet.list_records`；请求参数由授权派生，调用方无法扩范围；响应出现未授权字段按越界拒绝；审计行只写掩码 `file_id`/主机/表号/结果码/尝试次数。
- **离线结果（36 例，含 12 例真实 HTTPS 传输 + 4 例跨进程）**：合法读取经 reqwest 真实 TLS 连本机测试服务走完整链路（4 次请求：初始化 + 通知 + 读取 + 终止），args 含 `fields` 且不含 token；入口关闭、目标不符、表/字段越界、窗口过期、凭据主体不匹配或待补、写动作**零请求**；证书不可信/主机名不匹配在握手阶段失败（HTTP 请求 0）、重定向不跟随（目标 0 请求）、响应越界整页拒绝（无后续分页/重试）。**读取预算**：单次逻辑读取最多 3 次 `list_records`（含重建后重发、超时计入），耗尽即停止并返回最后错误；第 4 条成功响应不被取用。`P2TlsPolicy` 禁止关闭证书/主机名校验与跟随重定向，客户端强制 `.no_proxy()`。
- **第三轮补充（2026-11-22）**：`tools/call` 结果按 MCP 形状解包 `content[].text` 再校验字段；响应越界也在同一入口留脱敏审计（一行、掩码 `file_id`、无字段值），界面层尚未接入 P2；协议依据逐项列表见证据 §11，其中 `fields` 动作级支持、WPS 官方认证与错误码文档、会话 `DELETE` 仍为【待补】。
- **第四轮补充（2026-11-23：单次执行入口）**：`P2Grant` 增 `page_size`/`max_total_requests`/`terminate_allowed`；入口绑定首屏 `offset=0` 与签批分页大小，单次授权预检通过即占用、完成后不可重启（`P2_E_SINGLE_USE`）；每次发网前检查窗口剩余与整场预算，请求超时取 `min(窗口剩余, 传输层 timeout)`；动作计数 `initialize/notify/read/terminate/total` 如实返回并受上限约束（2/2/3/1，合计 ≤8，无探测余量）；初始化成功后发 `notifications/initialized`，读取成功后按开关发 `DELETE`，终止失败只做本地关闭；最后一次读取额度用完遇会话过期不再重建。回归全部由本机 HTTPS 服务计数：分页参数非法零请求、退避期间窗口到期即停、整场预算耗尽即停、重复启动零新增请求、越界后不可重启。
- **第五轮补充（2026-11-23：跨重启消费登记 / 越界脱敏 / 终止状态）**：`P2Grant` 增 `grant_id`；入口可接隔离 SQLite 状态库（`SqliteP2State`），在**任何发网动作之前**原子登记授权消费，冲突返回 `P2_E_ALREADY_USED`，状态库不可用/登记失败返回 `P2_E_STATE` 并本地停止；登记后即使进程中断也不得恢复，跨重启与两进程并发均只有一次取得执行资格。`preflight` 强制窗口 ≤15 分钟（`P2_MAX_WINDOW`）与整场 ≤8 次（`P2_MAX_TOTAL_REQUESTS`），超限零请求。响应越界文案改为固定提示 + 错误码 + 表号，不再回显远端字段名。新增 `P2Termination{Completed, Unconfirmed, Skipped(reason)}`：`DELETE` 失败显示「远端终止未确认，本地已关闭」且不追加请求；因窗口/预算未发送则记录原因。回归全部用本机 HTTPS 服务计数：重建入口零新增请求、并发只一个成功、登记后发网前中断、状态库不可用、超长窗口/超上限、终止失败、预算耗尽未发终止。
- **第六轮补充（2026-11-23：跨进程消费登记验收）**：用独立子进程（`current_exe --exact … p2_child_worker`）调用同一 `P2ReadOnlyEntry` 与同一 `SqliteP2State`，每个场景独立临时目录与授权 ID。重启场景 A 完成读取（4 次请求）退出后，B 用同一授权得 `P2_E_ALREADY_USED`、新增请求 0；并发场景两进程就绪后同时放行，`ok=1 used=1`、服务端总计 4；登记提交后、首次发网前中断场景由测试用 `PausingConsumption` 在 `INSERT` 提交后暂停，父进程确认服务端 0 请求后终止进程，重启后仍 `P2_E_ALREADY_USED`、请求仍 0。中断时点由文件标记固定，不依赖 `sleep`。
- **第七轮补充（2026-11-23：最小只读 CLI 离线验收）**：新增 `voucher-cli wps-p2-read`，复用同一 `P2ReadOnlyEntry`/`P2Grant`/`SqliteP2State`；端点主机白名单只允许 `p2-local.test`/`localhost`/`127.0.0.1`，默认 `--transport offline` 零发网，`loopback-tls` 必须显式 `--trust-root`，凭据为固定合成 token，`--check` 只做预检不建状态库；`fields` 为空即拒（逐列批准）。4 例集成用例覆盖预检、非回环端点拒绝、offline 失败后同授权不可重启、缺 CA 时不登记。**执行入口缺口仍在**：桌面 UI 未接 P2，CLI 只是受控执行候选，不构成 A2 首联入口。证据：[`2026-11-23-P2-CLI/入口证据.md`](../2026-11-23-P2-CLI/入口证据.md)。
- **仍缺**：真实端点与账号主体、真实服务端只读权限与请求轨迹、真实证书链/DNS 证据、首次联调的报文差异确认（离线按仓库回环传输与 MCP 公开规范接线，真实端点是否一致需现场确认）。证据、计数修复对照与逐项缺证见 [P2 入口证据](../2026-11-22-P2-只读入口/入口证据.md)。
- **结论**：守卫层、HTTPS 传输层与单次执行入口可提交复核；**真实端点/主体/权限未取证，P2 仍为未授权执行，A2 不签**。

**本地可证的两项约束**：①非白名单目标——`ensure_file_allowed`/`with_allowed_files` 用例直接断言未登记 `file_id` 被拒（S0-06）；②写请求在发出前被拒——`WpsConfig::validate` 在未获 S0 时拒绝非 mock 传输，且 `run_strict_mock_batch` 在快照门阻断时不进入 `execute`（S0-05/§4）。真实环境仍需一次「白名单外访问被拒」的请求样例。

| P2 只读取证可取得 | 需后续专项验收（C1–C6 等） |
