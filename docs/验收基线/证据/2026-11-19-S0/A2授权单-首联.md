## 2. 请求预算（按代码实况，签审可收紧）

| 动作 | 上限 | 代码依据 | 备注 |
|---|---|---|---|
| `initialize` | ≤2（首次 + 最多 1 次重建） | `P2ReadOnlyEntry::start_session` | 重建不重置读取预算 |
| `notifications/initialized` | ≤2（每次初始化后 1 次） | `start_session` 内 `counts.notify` | 通用 MCP 规范；WPS 是否必需【待补】 |
| `dbsheet.list_records` | ≤3（单次逻辑读取；含首次、重建后重发、超时/5xx 重试） | `P2_MAX_READ_ATTEMPTS` | 预算耗尽即停，最后一次额度用完不再重建会话 |
| `DELETE`（会话终止） | ≤1（仅读取成功后、`terminate_allowed`） | `terminate_allowed` + `P2Termination` | 失败只记「远端终止未确认，本地已关闭」，不重试 |
| 整场总请求 | ≤8（**仅适用单页单**） | `P2_MAX_TOTAL_REQUESTS` | 按上表分配，无探测余量；扫描运行另设上限 |
| 执行窗口 | ≤15 分钟 | `P2_MAX_WINDOW` | 每次发网前检查剩余；退避期间到期即停 |
| 单页记录数 | ≤50 | `grant.page_size` | 不追分页完整性 |

**禁止**：用上述额度探测其他动作、其他文件、其他表或其他字段；超出任一上限即停并留证。

## 4. 首联验收步骤与停止条件

**预期动作顺序**（全部计入 §2 预算）：`initialize` → `notifications/initialized` → `tools/call dbsheet.list_records`（`offset=0`、`page_size=50`、`fields=<批准字段>`）→（成功且允许时）`DELETE`。

**成功判据**：init 1 次；读取 1 次返回 `records` 且字段都在批准集合内；`P2Termination::Completed`（或按授权单选择不终止并记 `Skipped`）；服务端请求数 ≤4。

**立即停止并留证**（任一触发即关闭通道，授权不可重启）：

1. initialize 未返回 `Mcp-Session-Id`，或后续请求 404 后重建仍失败；
2. 响应不是 `result.content[].text` JSON，或解析后不是 `records` 结构；
3. 认证头被拒（401/403）或返回 400006 / 429（见 §6）；
4. 出现未授权字段、非批准表或非批准文件；
5. 需要发送§2 表外动作才能继续（例如服务端要求额外探测或额外参数）；
6. 窗口到点、预算耗尽、TLS/主机名/DNS 异常、审计出现 token 或字段值回显。

**报文与假设不符时**：停止本次 P2，把差异写入入口证据 §11 对应行并回填决策表 §1 的 A2 前置；重新申请需另批授权单与 `grant_id`。

## 6. 真实 429 / 400006 处理（拟批条款）

- **自然出现**：记录错误码、时间、请求序号与脱敏轨迹后**立即停止**，不重试、不续期。
- **未自然出现**：保留「未观察，待专项验收」，**不得刷请求触发**。
- **400006 主动演练**：需签审人另批隔离账号与窗口；在 A2 签前明确该缺证是否阻塞 S0（建议不阻塞 S0-05 的守卫层结论，但阻塞 S0-07 的真实部分）。
