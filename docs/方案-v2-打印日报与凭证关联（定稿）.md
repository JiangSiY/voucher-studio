## 二、批次① 打印日报改版（范围与验收）

**改**：正文/表头/金额/合计 12pt；标题保持 14pt；页脚 9pt；图片 caption 10pt；列宽按 T1；行高 8/12mm；**贪心分页**（按每行实际高度排，不牺牲短摘要页容量）；金额列**独立预留 40mm**（右对齐仍在 200mm，但文本被限制在列内，绝不侵入「对方账户」）；合计行、行底细线、页脚按新几何重排。

**删**：单份 PDF（`pdf::generate` 与其卡片版式、`PdfOptions.card_style/columns`、`export_pdf` 命令、打印中心的卡片风格与每行列数控件）、年度汇总报表（`generate_yearly_report` 及其命令、洞察页按钮）。

**两道防重叠守卫**：① 几何不变量单测（金额估算宽 ≤ 金额列可用宽 − 2mm；行高 ≥ 字号×1.4；文本右端 ≤ 200mm；每页内容 + 合计行 ≤ 可用高度）；② 样张探针（固定合成数据生成日报，读回文本框位置断言）。

**验收**：① ≥12pt；② 金额不入侵「对方账户」且右端 ≤200mm；③ 行距 ≥ 字号×1.4、行不重叠；④ 合计行与最后一行/页脚各 ≥3mm 净空；⑤ 每页行数按新几何且页脚总数正确；⑥ 摘要换行不越列、截断处可见「…」；⑦ 图片不越格、caption 不压图不越页脚；⑧ 同日两次导出一致；⑨ 批次张数与「从未导出」口径不变。

## 三、批次② 关联（范围）

- 表：`voucher_links`(a_id,b_id,kind ∈ {explains,detail},note,created_at) + `voucher_groups`(title,note,created_at) + `voucher_group_items`(group_id,voucher_id,sort_order) + `voucher_link_events`(append-only：link_id,a_id,b_id,kind,action,at，**刻意不加外键**)。
- 升级：走 v5–v8 幂等只增（`SCHEMA_V9`），**绝不 bump `SCHEMA_VERSION`**；补一条"老库升级不清库"用例（照抄 `dup_decisions_upgrade.rs`）。
- 服务/命令：建/解关联、建/改组、组内增删排序、按凭证查两向关联与所属组；命令层不得直连 db；新增命令三处同步（core / `main.rs` / `client.ts`）。
- 前端：右栏「相关凭证」（两向、带说明文本）＋「所属组」（组内明细节与排序）＋「无图凭证」创建入口；列表加关系徽标与「+N」展开；「未被佐证」筛选（同时改 `build_filter_where` 与 `neighbor` 三条 SQL 与 `VoucherQuery` 两侧）。
- 纪律：**组的合计标为派生值**，不改写任何金额合计口径；删除走 CASCADE，留痕进审计表；导入路径**不得产生悬空关联**。

## 四、批次③ 打印接佐证（范围）

- 日报默认**带佐证**（可单次关闭）：`主凭证页 + 附件清单页（按关系类型分类小计：张数/金额）+ 附件逐页`；
- 导出**关联清单**（源凭证/关系类型/目标/说明/金额-可空）；
- **附页绝不写 `export_items`**（批次张数、导出覆盖度、"从未导出"一律不变）；
- 与批次①的版式配合：清单页复用同一套 12pt 表格样式。

## 五、不做（除非另行要求）

放宽「一图一凭证」 · 带金额的关联（核销/冲销/借款抵扣） · 「报销」关系类型 · 把关联排进日报正文表格 · 删 Excel/CSV/导出历史/账本式模板/附件图片页/增强版开关 · 本方案阶段之外的任何重构。
